## Implemented

- Code-signing preflight uses `CSC_LINK` or `WIN_CSC_LINK`.
- `FLUENT_AI_REQUIRE_SIGNING=1` blocks packaging when no certificate is configured.

- `package.ps1` runs signing preflight before packaging and release finalization after installation smoke.

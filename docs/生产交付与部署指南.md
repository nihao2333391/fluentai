# 生产交付与部署指南

本文说明如何从完整仓库构建 Windows 安装包、检查交付文件，并在目标机器上安装 Fluent AI。命令以仓库当前的 `package.json`、`scripts/package.ps1`、`scripts/prepare-sidecar.ps1` 和 `electron-builder.yml` 为准。

## 1. 交付方式概览

项目使用 Electron 打包 Windows x64 桌面应用，并把 Python 3.12 运行时、后端代码及 Python 依赖一起放入 Sidecar（随应用部署的本地后端进程）。最终用户无需单独安装 Node.js、pnpm 或 Python。

最终用户仍需准备 ANSYS Fluent Meshing 2025 R2 和适用于其使用场景的有效 ANSYS 授权。应用通过 PyFluent 连接本机 Fluent；PyFluent 本身不包含 Fluent 软件或其商业授权。

## 2. 构建机环境

建议使用干净、可联网的 Windows x64 构建机。仓库当前要求：

| 软件/条件 | 要求 | 用途 |
|---|---|---|
| Windows | Windows x64 | 构建和安装 NSIS Windows 安装程序 |
| Node.js | 24 或更高版本 | 构建 Electron 主进程和界面 |
| pnpm | 12.5.1 或更高版本；项目声明版本为 12.5.1 | 安装前端依赖和执行项目脚本 |
| Python | Python 3.12，可通过 `py -3.12` 启动 | 准备随应用交付的后端运行环境 |
| ANSYS Fluent | 2025 R2 | 运行 Fluent 连接及 Meshing 工作流验证 |
| 网络 | 依赖安装期间可访问对应软件源 | 下载锁定的 Node.js 和 Python 依赖 |

打包脚本还使用 Windows PowerShell、`curl.exe` 和 Electron Builder。构建前确认它们可用，并预留安装包及 Sidecar 所需磁盘空间。

## 3. 获取仓库并准备依赖

在 PowerShell 中执行：

```powershell
git clone https://gitee.com/alcohol-free-beverage-station/fluent-ai-for-aic2026.git
Set-Location fluent-ai-for-aic2026

node --version
pnpm --version
py -3.12 --version

pnpm install
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-dev.txt
```

`pnpm install` 按项目锁文件安装 Node.js 依赖。Python 环境通过 `backend/requirements-dev.txt` 安装，其中包含运行后端所需的依赖和开发检查依赖。

## 4. 构建安装包

先运行项目检查：

```powershell
pnpm check
```

然后生成 Windows x64 安装包：

```powershell
pnpm package:win
```

该脚本按顺序执行：

1. TypeScript 类型检查和 Electron 应用构建。
2. 准备独立 Python Sidecar，包含 Python 3.12、后端代码和运行依赖。
3. 启动打包后的 Sidecar，并检查本地 API 握手和就绪状态。
4. 检查代码签名配置并构建 NSIS 安装程序。
5. 静默安装生成的安装包，启动安装版应用并运行 Sidecar 冒烟检查。
6. 生成安装包 SHA-256 文件和 `release-manifest.json`。

脚本成功后，预期产物位于 `release` 目录：

```text
release\FluentAI-0.1.0-x64-Setup.exe
release\FluentAI-0.1.0-x64-Setup.sha256
release\release-manifest.json
```

安装包文件名中的版本号来自根目录 `package.json` 的 `version` 字段。发布新版本前应先更新该版本号，再构建安装包。

## 5. 代码签名

项目支持使用 Authenticode 对 Windows 安装包签名。签名证书和密码通过环境变量提供：

```powershell
$env:CSC_LINK = "证书文件路径或受支持的证书地址"
$env:CSC_KEY_PASSWORD = "证书密码"
```

也可以使用 `WIN_CSC_LINK` 提供证书地址。若发布要求必须签名，设置：

```powershell
$env:FLUENT_AI_REQUIRE_SIGNING = "1"
```

此时缺少证书配置或生成的安装包签名无效，发布流程会失败。签名完成后检查 `release-manifest.json` 中的 `authenticode_status` 和 `signer_subject`。不要把证书密码写入仓库、日志或交付说明。

## 6. 发布前检查

发布人员应逐项确认：

- `pnpm check` 已完成，结果符合当前发布要求。
- `pnpm package:win` 成功完成，安装版冒烟检查通过。
- 安装包版本号与计划交付版本一致。
- 使用 `release\FluentAI-<版本>-x64-Setup.sha256` 核对安装包哈希，并通过可信渠道交付安装包和校验文件。
- 按发布要求确认 Authenticode 签名状态；若要求签名，状态应为有效且签名者正确。
- 检查安装包中随附的第三方许可证及适用的 NOTICE。项目依赖和许可证核对记录见 [开源及第三方资源使用清单](开源及第三方资源使用清单.md)。
- 确认交付团队具备适用于目标使用场景的 ANSYS Fluent 授权。项目安装包不提供 ANSYS Fluent 本体或许可证。
- 安装包、哈希文件和 release manifest 一并归档；不要把 `.venv`、`node_modules` 或临时 `build` 目录当成交付安装包。

## 7. 最终用户机器要求

目标机器需要：

- Windows x64。
- 已安装 ANSYS Fluent Meshing 2025 R2，并具备有效且适用的 ANSYS 授权。
- 若使用本机启动 Fluent，能够定位 `fluent.exe`；若使用既有 Fluent 会话，确保会话符合应用连接要求。
- 足够的磁盘空间保存安装程序、应用数据、SQLite 数据库和备份。

最终用户无需安装 Node.js、pnpm 或 Python，因为这些运行组件由安装包提供。

## 8. 安装和首次启动

1. 从可信的交付位置取得安装程序、SHA-256 文件和发布信息。
2. 使用 PowerShell 核对 SHA-256。例如：

   ```powershell
   Get-FileHash .\FluentAI-0.1.0-x64-Setup.exe -Algorithm SHA256
   Get-Content .\FluentAI-0.1.0-x64-Setup.sha256
   ```

   确认计算出的哈希与 `.sha256` 文件中的值一致。
3. 双击安装程序，按向导选择安装目录。
4. 安装后启动 Fluent AI，等待界面显示“FastAPI 侧车 · 已就绪”。
5. 打开“设置 → Fluent Meshing 连接”，配置 Fluent 路径和连接方式，并运行连接诊断。
6. 如需 AI 工程辅助功能，按应用设置配置模型服务和 API 凭据。
7. 参考[用户操作指南](用户操作指南.md)完成模型导入、预设配置和工作流操作。

应用本地数据默认保存在：

```text
%APPDATA%\fluent-ai
```

卸载程序默认保留用户数据。迁移或卸载前，按用户操作指南备份需要保留的数据库和配置。

## 9. 已知发布注意事项

- 未配置签名证书时，安装包可能显示未知发布者提示。是否允许交付应按组织或赛事发布要求决定。
- Fluent AI 是 ANSYS Fluent 的外部自动化应用，不是 ANSYS 官方产品；ANSYS、Fluent 等名称及软件许可归其权利人所有。
- Fluent 版本升级后，应重新验证 PyFluent 连接、Meshing 参数映射和工作流行为。
- 详细使用步骤和问题排查见[用户操作指南](用户操作指南.md)；构建验证记录见 `docs/poc/reports/installer-smoke.json` 和 `docs/poc/reports/packaging-sidecar.json`。

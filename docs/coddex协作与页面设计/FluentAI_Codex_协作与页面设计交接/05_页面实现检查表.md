# 05｜页面实现检查表（Codex 对照真实程序自检）

**用法：完成一项勾选一项，报告中附测试结果。此处不代表已经实现。**

## 模板编辑页布局

- [ ] 原导航/顶栏与 Fluent Meshing 模板步骤、参数输入完整保留；Agent 只占**右侧**。
- [ ] Agent 默认约 380–440px 的建议宽度，可收起；编辑主表单保留有效宽度，窗口过窄时改 Drawer 或等效布局。
- [ ] 表单和消息区分别独立滚动；聊天输入区固定底部，消息多时不推出画面。
- [ ] 右侧标题显示“工程辅助 Agent”，当前全局模型只读，能力查看不拥有工具编辑权限。
- [ ] 收起/展开不丢会话，异常断线不伪装为完成。

## 聊天交互

- [ ] 第一次进入模板有欢迎及快捷问题，点击快捷问题是真实发送；“暂时不用”能收起。
- [ ] 第一次进入 Add Boundary Layers 设置有专业主动引导，之后不重复刷相同提示。
- [ ] 底部支持多行输入、发送、停止；Enter 与 Shift+Enter 合理，发送禁用依据真实 Run 状态。
- [ ] `+` 入口能上传真实附件/图片，有附件缩略图、删除、上传失败提示和模型能力降级提示。
- [ ] 大段历史不自动打断用户阅读，能跳到最新消息。
- [ ] 用户明确输入完整参数直接采用；图片识别不确定项/AI 假设进入待确认状态。

## 专业分析流程

- [ ] 简单概念问题不用每次触发知识检索或数值工具。
- [ ] 方法比较卡能够选择 Smooth、Uniform 两条路线，不强制接受 AI 推荐。
- [ ] Smooth 检查 3 项输入，不要求 U/D/喉部信息。
- [ ] Uniform 检查 5 项输入，不强制喉部局部速度或开发新的速度计算算法。
- [ ] 缺参数时能明确指出哪一项及用途，不无限循环追问。
- [ ] 真实执行工具才能出现工具“计算完成”卡；工具失败显示真实错误。
- [ ] 结果卡展示工具输入、单位、关键公式/中间值、结果、来源、假设、实际 Fluent 参数映射状态。
- [ ] 复制参数的值正确；**Agent 不自动写左侧表单**。
- [ ] 输入更新后旧推荐能标过期；回到模板/切换分支后历史与结果仍在。

## 设置页 AI 模型配置

- [ ] 原“设置”页**向下滚动**能看到 AI 模型配置，不新增侧边栏菜单。
- [ ] 基础字段供应商、Model ID、按需 Base URL、API Key；Key 掩码且已有密钥不会因空输入被误覆盖。
- [ ] 文本、工具、图片、流式能力测试的状态来自实际检测，不是静态徽标。
- [ ] 模型能力不足仍能启用并降级，前端与后端共同遵守。
- [ ] 所有 Agent 只有一个当前全局生效 API，无目录/模板独立覆盖入口。
- [ ] 头部的模型设置跳转能准确定位现有设置页中的 AI 模型配置区。

## 交付与质量

- [ ] 仅使用现有项目真实 API 与 Fluent 版本已核实的字段。
- [ ] 相同模板刷新/重进，消息/工具记录/输入不会丢；不同模板不会串会话。
- [ ] 真实网络/模型/工具不可用时有用户看得懂的错误与下一步，不假装成功。
- [ ] 进行了原有模板表单、模型选择、Fluent 步骤的回归检查。
- [ ] 给出代码路径、测试结果、已知限制及本次开发日志。
- [ ] HTML 页面预览仅作设计参考，不算后端集成验收。

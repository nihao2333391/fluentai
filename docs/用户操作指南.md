## 0. 先读这一页（30 秒）

Fluent AI 是一个**本机运行的 Windows 桌面应用**：把重复的 Fluent 设置做成可复用预设，连接真实的 Fluent 会话，写入参数后逐项回读验证。

开始操作前，请先记住三条硬边界：

- **不生成网格。** Meshing 预设应用会导入几何、校验名称、写入参数，但一定停在 `Generate the Surface Mesh` 和 `Generate the Volume Mesh` 之前。表面网格与体网格要在 Fluent 中由你继续生成。
- **名称必须精确匹配。** 边界、Face Zone、Region、局部尺寸标签等名称来自目标模型；任何一个对不上，应用会在写入前中止并列出缺失名称。本应用不做模糊匹配，也不会静默改名。
- **安装包尚未签名。** 当前安装包为 `NotSigned`，Windows SmartScreen 可能提示。请先核对 SHA-256，再决定是否继续安装。

第一次使用的推荐顺序：

1. 安装并启动应用，等待顶部「FastAPI 侧车 · 已就绪」。
2. 打开 **设置 → Fluent Meshing 连接**，填写 `fluent.exe` 路径，选择「启动新会话」和「显示 GUI」，保存并连接。
3. 点「连接与读写诊断」，确认能读到参数并回读一致。
4. 打开 **我的模型 → 导入模型**，导入目标几何（建议 `.pmdb`）。
5. 打开 **Meshing 自动化 → 创建 Meshing 自动化**，按任务树勾选参数并保存。
6. 回到 **Meshing 自动化**，点该预设的 ▶，选择几何，应用。
7. 看结果提示：写入并回读多少项、是否停在网格生成之前、是否有缺失名称。
8. 需要继续生成网格时，切到 Fluent GUI 窗口完成；完成后断开连接或退出应用。

每次点击「应用」之前的 60 秒检查：

- [ ] 目标几何已导入「我的模型」，文件没有被移动或改名。
- [ ] 预设里的标签、Zone、Region 名称与目标模型完全一致。
- [ ] 复合子任务名称不重复，且每一个都选了至少一项参数。
- [ ] 若要让应用自动连接，连接设置需已保存（未保存的输入不会参与自动连接）。
- [ ] 当前没有其他任务在运行；Fluent 许可可用。
- [ ] 已确认本次只做到「生成网格之前」。

## 1. 产品概览

### 1.1 它解决什么问题

在 Fluent 里逐项点选 Solver 设置、逐项配置 Meshing 工作流，既慢又容易漏。Fluent AI 把这些设置保存成**预设**，在需要时一次性写入真实 Fluent，并把每一项的实际值读回来核对。它的价值是**可复用、可核对、可追溯**，而不是替代 Fluent 本身。

应用由界面、Electron 主进程和本机 FastAPI 服务组成，但日常使用只需要理解两件事：

- 界面（Electron + React）负责选择、编辑和展示结果。
- 本机 FastAPI 服务（界面里叫「侧车」）负责连接 Fluent、读写参数、保存 SQLite 数据。侧车只监听 `127.0.0.1`，每次启动使用随机端口和临时令牌，不对外网开放。

### 1.2 能做什么

| 能力                  | 入口                                        | 结果                                                                |
| --------------------- | ------------------------------------------- | ------------------------------------------------------------------- |
| 创建 Meshing 预设     | Meshing 自动化 → 创建 Meshing 自动化        | 保存 Watertight / Fault-tolerant 的任务与参数；可保存具名复合子任务 |
| 实时应用 Meshing 预设 | 网格划分自动化 → 行末 ▶                     | 启动会话、批量导入模型、逐步骤写入/回读并执行工作流任务             |
| Meshing 直连读写诊断  | 设置 → Fluent Meshing 连接 → 连接与读写诊断 | 读取代表参数，并把同一个值写回后回读验证                            |
| 管理模型              | 我的模型 → 导入模型                         | 登记算例/网格/几何；在 Fluent 中打开算例；关联默认自动化            |
| 任务进度与取消        | 顶部「任务」徽标                            | 查看阶段、进度；在阶段之间协作式取消                                |
| 数据备份与恢复        | 设置 → 数据安全                             | 每日自动备份、手动备份、恢复前安全备份                              |

### 1.3 明确不做的事

| 不做                         | 说明                                                          |
| ---------------------------- | ------------------------------------------------------------- |
| 生成表面网格或体网格         | 这是刻意设计的停线；网格生成仍在 Fluent 中完成                |
| 保存修改后的 `.wft` / `.cas` | 应用只写会话状态，不替你保存工程文件                          |
| 几何建模、修复、简化         | 只导入已有几何；不修改几何拓扑                                |
| 求解计算                     | 可以预置迭代次数、残差等参数，但不在本应用里启动求解          |
| 覆盖 Fluent 全部设置         | Solver 静态目录 39 项，加载算例后再动态发现材料与部分边界字段 |
| 模糊匹配名称                 | 找不到就中止，避免把参数写到错误对象上                        |
| 复制模型文件                 | 模型库只登记原文件路径；原文件移动/删除会导致后续打开失败     |
| 提供三维视口                 | 没有几何/网格三维预览；请在 Fluent 中查看                     |

### 1.4 两条主流程

Meshing 主流程：

```text
导入几何到「我的模型」
        ↓
创建/维护 Meshing 预设（任务树 + 参数 + 具名子任务）
        ↓
设置页保存 Meshing 连接（launch + GUI 推荐）
        ↓
Meshing 自动化 → 应用 → 选择几何
        ↓
导入几何 → 校验名称 → 创建子任务 → 写入参数 → 逐项回读
        ↓
停在 Generate the Surface Mesh / Generate the Volume Mesh 之前
        ↓
在 Fluent 中继续生成网格、检查、保存
```

Solver 自动化仍保留后端接口供开发集成使用，但桌面界面已移除「我的自动化」板块。

## 2. 运行环境与安装

### 2.1 环境要求

| 项目            | 要求                                                          |
| --------------- | ------------------------------------------------------------- |
| 操作系统        | Windows 10 / 11，x64                                          |
| Fluent          | ANSYS Fluent 2025 R2（25.2.0），本机已安装且许可可用          |
| Fluent 路径示例 | `D:\Ansys2025R2\ANSYS Inc\v252\fluent\ntbin\win64\fluent.exe` |
| Python          | 安装版已内置 Python 3.12 与 PyFluent 0.42.1，无需单独安装     |
| 磁盘            | 安装包约 170 MiB；安装后约 360 MiB；数据与备份另计            |
| 显示            | 建议 1280×800 以上；窗口默认 1180×760，最小 920×600           |
| 权限            | 按当前用户安装，通常不需要管理员权限；可选择安装目录          |
| 网络            | 日常操作全部在本机完成；Fluent 许可服务按你的环境要求联网     |

> **只支持 Fluent 2025 R2。** 应用的连接配置固定使用 `25.2.0`，参数目录、Meshing schema 与实机验证都基于 2025 R2。其他版本可能能连上，但不在验证范围内。

### 2.2 安装步骤

1. 关闭正在运行的 Fluent AI 旧版本，以及由它启动的 Fluent 会话。
2. 核对安装包完整性（推荐）：
   ```powershell
   Get-FileHash .\FluentAI-0.1.0-x64-Setup.exe -Algorithm SHA256
   ```
   正常值应为：
   ```text
   BFD8A0C0F865D7EFB80269AEB568CB81F434605039B40541C1D10D8322413CA0
   ```
3. 双击 `FluentAI-0.1.0-x64-Setup.exe`。若 SmartScreen 提示「Windows 已保护你的电脑」，选择「更多信息 → 仍要运行」。出现提示的原因是安装包尚未做 Authenticode 签名。
4. 在安装向导中选择安装目录（默认按当前用户安装），完成安装。安装程序会创建桌面快捷方式与开始菜单项「Fluent AI」。
5. 启动 Fluent AI。首次启动时侧车要预加载 PyFluent，冷启动可能需要十几秒到一分钟；顶部徽标会从「启动中」变为「已就绪」。
6. 打开 **设置**，填写 Fluent 路径并保存。此时先不要急着建预设，先做一次连接与读写诊断。

### 2.3 首次启动会发生什么

- 应用自动启动本机 FastAPI 侧车；侧车在 `127.0.0.1` 上选择一个随机端口，并使用一次性令牌鉴权。
- 在 `%APPDATA%\fluent-ai\data\` 下创建/打开 SQLite 数据库 `fluent-ai.db`。
- 如果最近 24 小时内没有备份，侧车启动时自动创建一份每日备份（`data\backups\`）。
- 首次启动按 Windows 显示语言选择中文或英文；之后可在设置中手动切换，选择会持久保存。
- 主题默认「跟随系统」；可在设置中改为浅色或深色。
- 默认打开 **网格划分自动化** 页面；侧栏顺序为「网格划分自动化 → 我的模型 → 设置」。

### 2.4 升级、卸载与数据保留

- **升级**：退出应用后直接安装新版本，数据库与备份保留在 `%APPDATA%\fluent-ai\data\`。
- **卸载**：通过 Windows「设置 → 应用 → Fluent AI」卸载。安装器默认**不删除应用数据**（`deleteAppDataOnUninstall: false`），卸载后 `%APPDATA%\fluent-ai` 仍在。
- **彻底清理**：确认不再需要数据后，先手动备份 `data\`，再删除 `%APPDATA%\fluent-ai`。这会移除数据库、备份、界面缓存与凭据缓存，操作不可撤销。

## 3. 界面总览

### 3.1 主窗口

- **左侧栏**：品牌区 + 两组导航。「工作区」下有网格划分自动化、我的模型；「系统」下有设置。底部可折叠侧栏。
- **顶部栏**：左侧是应用名与当前路由路径；右侧是「任务」徽标和「FastAPI 侧车」状态徽标。
- **内容区**：页面标题、说明、右上角操作按钮，以及列表/表单/结果卡片。

### 3.2 页面地图

| 页面                | 主要用途                         | 关键操作                               |
| ------------------- | -------------------------------- | -------------------------------------- |
| Meshing 自动化      | Meshing 预设的列表与入口         | 创建、应用、删除、刷新                 |
| 创建 Meshing 自动化 | 按真实任务树编辑 Meshing 预设    | 选工作流、勾选参数、加子任务、保存     |
| 我的模型            | 模型/几何登记                    | 导入模型、在 Fluent 中打开、关联自动化 |
| 设置                | 连接、主题、语言、备份、凭据状态 | 保存连接、连接/断开、诊断、备份/恢复   |

### 3.3 两个状态徽标

**FastAPI 侧车徽标**（右上，点击展开）：

| 状态   | 含义                     | 建议动作                               |
| ------ | ------------------------ | -------------------------------------- |
| 已就绪 | 侧车可用，业务请求可发   | 正常使用                               |
| 启动中 | 正在启动/预加载 PyFluent | 等待，不要重复点击                     |
| 重启中 | 正在重启侧车             | 等待完成                               |
| 未启动 | 侧车未运行               | 点击「重启侧车」                       |
| 异常   | 启动或运行失败           | 展开看消息；先重启，仍失败再看故障排查 |

弹层里还能看到侧车版本、PID 与 `127.0.0.1:<端口>`，并提供「重启侧车」。侧车异常时，页面会显示错误态，业务操作不可用。

**任务徽标**（右上，点击展开）：

- 显示「无活动任务」或「N 个活动任务」；每 2 秒刷新一次。
- 弹层列出最近任务（最多 20 条），包含状态、类型、更新时间、消息与进度条。
- 排队中/运行中的任务可点「取消任务」。取消是协作式的：在两个阶段之间生效，正在执行的单次 Fluent 调用不会被强行打断。

### 3.4 语言与主题

- **语言**：设置 → 界面外观 → 中文 / 英文，立即生效并持久保存。中文参数术语取自 ANSYS Fluent 2025 R2 汉化资源，英文使用 Fluent 原版字段名。
- **主题**：设置 → 界面外观 → 浅色 / 深色 / 跟随系统，立即生效。

## 4. 连接 Fluent

连接是 Meshing 与 Solver 两套独立会话。**设置页有两个连接卡片：Fluent 连接（Solver）与 Fluent Meshing 连接。** 两者互不影响，可以分别连接/断开。

### 4.1 两种连接模式

| 模式   | 界面名称     | 适用场景                          | 注意                                                                           |
| ------ | ------------ | --------------------------------- | ------------------------------------------------------------------------------ |
| launch | 启动新会话   | 日常推荐；由应用启动并管理 Fluent | 启动需 300 秒内完成；退出应用通常会清理由它启动的会话                          |
| attach | 连接现有会话 | 连接你已手工启动的 Fluent         | 需要正确的 host/port；Meshing 的 attach 只能连接与看状态，**参数读写会被阻断** |

> **Meshing 生产环境请用 launch。** PyFluent 0.42.1 对 Fluent 2025 R2 的 legacy Meshing workflow 在 attach 模式下读取会报 `StringVector is not iterable`。应用会明确阻断读写，避免部分写入。看到「附加模式可以建立连接，但……读写验证请使用启动新会话」的黄色提示时，请切回 launch。

### 4.2 配置 Solver 连接

1. 打开 **设置 → Fluent 连接**。
2. **连接模式**：选择「启动新会话」（推荐）。
3. **Fluent 可执行文件**：填写 `fluent.exe` 的完整路径，不要填快捷方式。
   示例：`D:\Ansys2025R2\ANSYS Inc\v252\fluent\ntbin\win64\fluent.exe`
4. **主机 / 端口**：launch 模式保持 `127.0.0.1`、端口留空；attach 模式填写现有会话的 gRPC 端口。
5. 点 **保存连接设置**。
6. 点 **连接**。成功后卡片标题显示「已连接」，并显示版本、PID、`host:port`。
7. 用完点 **断开**，释放会话。

> launch 模式下，Solver 连接卡片固定以 **GUI 方式、单处理器**启动 Fluent，启动超时 300 秒；这些值不在界面上暴露。需要后台模式时，请使用 Meshing 卡片，或等待后续版本。

### 4.3 配置 Meshing 连接

1. 打开 **设置 → Fluent Meshing 连接**。
2. **连接模式**：选择「启动新会话」。
3. **Meshing 会话模式**：
   - **显示 GUI**：推荐首次使用、需要人工检查或继续生成网格时使用。
   - **后台运行**：适合批量/无人值守；你看不到 Fluent 窗口。
4. **Fluent 可执行文件**：填写同一个 `fluent.exe` 路径。若留空，应用应用预设时会回退使用 Solver 路径；但连接时建议显式填写，避免歧义。
5. **主机 / 端口**：launch 保持默认；attach 填写现有 Meshing 会话的端口。
6. 点 **保存连接设置**，再点 **连接**。
7. 状态变为「已连接」后，下方「Meshing 工作流」选择 `Watertight Geometry` 或 `Fault-tolerant Meshing`。

> **先保存，再应用。** 应用 Meshing 预设时，如果会话尚未连接，应用会读取**已保存**的 Meshing 连接设置自动连接；未保存的输入不会生效。

### 4.4 使用「连接与读写诊断」

这是本版最直接的「读—写—回读」自检，不会改变参数语义：它先读取一组代表参数，再挑一个已读到的值，把**同一个值**写回去并回读比对。

1. 确认 Meshing 已连接（状态为「已连接」）。
2. 在「Meshing 工作流」选择要检查的工作流。
3. 点 **连接与读写诊断**，等待按钮从「正在读取并回读验证」恢复。
4. 看结果卡片：
   - **发现 N 个任务**：当前工作流暴露的任务数。
   - **已读取 N 项当前值**：代表参数是否读到。
   - **已写入并回读 N 项**：写回验证通过的数量。
   - 下方列出每项的 `任务 / 参数` 与当前值。
5. 出现失败时，先看错误消息；attach 模式的 `StringVector` 报错请改用 launch。

诊断读取的代表参数：

| 工作流         | 读取项                                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Watertight     | `import_geometry.file_format`、`import_type`、`length_unit`；`create_surface_mesh.cfd_surface_mesh_controls.min_size`、`max_size`；`create_volume_mesh.volume_fill` |
| Fault-tolerant | `import_cad_and_part_management.file_loaded`；`mesh_controls_table.global_max`、`target_growth_rate`                                                                |

> 诊断通过只说明「连接、读取、写回、回读」这条链路是通的，不代表你的预设名称一定能在目标几何上匹配。名称校验发生在应用预设时。

### 4.5 连接检查清单

- [ ] Fluent 路径指向真实 `fluent.exe`，不是快捷方式。
- [ ] Fluent 版本为 2025 R2，许可可用。
- [ ] 没有另一个 Fluent 实例占用同一许可/端口。
- [ ] launch 模式下端口留空；attach 模式下 host/port 与实际会话一致。
- [ ] Meshing 读写使用 launch，不使用 attach。
- [ ] 保存连接设置后，连接状态确实变为「已连接」。
- [ ] 诊断能读到参数并写回成功。

## 5. 模型库

### 5.1 导入模型

1. 打开 **我的模型**。
2. 点 **导入模型**，在系统文件对话框中选择文件（对话框标题为 `Select Fluent model file`）。
3. 导入成功后，列表中会出现模型名称（默认取文件名）、完整路径、大小、默认自动化与导入时间。
4. 需要刷新元数据时，重新进入页面或点右上角 **刷新**。

模型库保存的是**原文件的绝对路径**，不会把文件复制到应用目录。原文件被移动、改名或删除后，打开/应用会失败。

### 5.2 支持的文件格式

| 用途                                   | 扩展名                                                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Solver 算例/网格（可在 Fluent 中打开） | `.cas`、`.cas.h5`、`.msh`、`.msh.h5`                                                                         |
| Meshing 几何（用于应用 Meshing 预设）  | `.dsco`、`.scdoc`、`.step`、`.stp`、`.iges`、`.igs`、`.pmdb`、`.fmd`、`.tgf`、`.x_t`、`.x_b`、`.sat`、`.sab` |

> 文件对话框统一列出上述格式。**「在 Fluent 中打开」按钮只对 Solver 算例/网格启用**；几何文件请走 Meshing 应用流程。对于 Meshing，经验证最稳的入口是 Workbench 生成的 `.pmdb`；直接导入 `.dsco` 在独立 Fluent Meshing 中可能卡住。

### 5.3 在 Fluent 中打开算例

1. 在 **我的模型** 找到 `.cas` / `.cas.h5` / `.msh` / `.msh.h5` 行。
2. 点行末的「电源/接口」图标（打开）。
3. 若尚未连接，应用会按已保存的 Solver 连接设置自动连接，然后载入算例。
4. 成功提示「模型已在 Fluent 中打开」；失败会弹窗给出原因。

### 5.4 关联自动化

1. 在模型行点「链接」图标（关联自动化）。
2. 选择要关联的 Solver 自动化。
3. 勾选「默认自动化」表示该模型默认使用此预设。
4. 保存后，模型行的「默认自动化」列显示对应标签。

关联关系保留在数据层，供接口和后续功能使用；它不会自动执行任何写入。

### 5.5 注意事项

- 模型名称默认取文件名；重名不会阻止导入，但文件路径必须唯一。
- 文件大小与修改时间在导入时记录；源文件变化后可用刷新接口更新，但界面暂未提供单独按钮。
- 文件选择令牌只在当前应用进程内有效，重启后失效；已导入的模型不受影响，但重新选择文件会生成新令牌。

## 6. 创建 Meshing 自动化

### 6.1 先理解「预设」是什么

一个 Meshing 预设由三部分组成：

- **工作流类型**：Watertight 或 Fault-tolerant，二者任务树不同，不能混用。
- **参数项**：每项指向「任务 → 参数路径」，并带一个值；只保存你勾选过的项。
- **复合子任务**：某些任务（如 Add Local Sizing、Add Boundary Layers）需要先创建一个具名控制，再给这个控制填参数。预设会记录子任务名称与参数。

应用时，引擎只做三件事：导入几何、创建具名子任务、把参数写入任务/子任务状态。它**不执行**这些任务（除了导入几何），更不会生成网格。

### 6.2 创建步骤

1. 打开 **Meshing 自动化**，点右上角 **创建 Meshing 自动化**。
2. 填写基本信息：
   - **名称**（必填，最多 120 字符；同类预设不可重名）。
   - **模型类别**（可选，例如「文丘里管系列」；用于人工分类）。
   - **参考模型**（可选，从模型库选择；仅作参考，不参与名称校验）。
   - **描述**（可选，最多 2000 字符）。
3. 在右上角选择工作流：**Watertight Geometry** 或 **Fault-tolerant Meshing**。切换工作流会重新加载任务树，已勾选项会清空。
4. 在左侧任务标签页中逐项勾选参数、填写目标值。
5. 需要具名控制时，在复合任务里点 **添加复合子任务预设**，填写名称与参数。
6. 点 **保存 Meshing 自动化**。保存前会做预设结构校验；通过后写入数据库并返回列表。

编辑已有预设：在网格划分自动化列表点击 **编辑**。编辑器会回填名称、描述、模型类别、参考模型、工作流参数和具名复合子任务；工作流类型保持锁定，保存时覆盖原自动化，不创建副本。

### 6.3 选 Watertight 还是 Fault-tolerant

|          | Watertight Geometry   | Fault-tolerant Meshing                                                                       |
| -------- | --------------------- | -------------------------------------------------------------------------------------------- |
| 适合     | 封闭、干净的 CAD/几何 | 有泄漏、脏几何、需要容错处理的模型                                                           |
| 任务数   | 11 个顶层任务         | 25 个顶层任务                                                                                |
| 典型入口 | Import Geometry       | Import CAD and Part Management（Part Management + FMD/PMDB）                                 |
| 本版限制 | 全部任务可编辑        | `Identify Construction Surfaces`、`Create Local Refinement Regions` 两个复合任务的参数不可用 |

> 不确定时先用 Watertight。它的任务链更短，实机验证覆盖也最完整（11 个任务、427 项参数可读）。Fault-tolerant 的两个复合任务受 PyFluent `RecursionError` 限制，界面会给出参数不可用警告；不要凭印象补字段。

### 6.4 参数编辑规则

- 每个叶子参数前有复选框：**勾选才会写入预设**。未勾选的项不保存，也不会在应用时写入。
- 控件类型由参数类型决定：
  - 布尔值 → 开关。
  - 有候选值 → 下拉框；列表型 → 多选。
  - 整数/浮点 → 数字输入框。
  - 字符串 → 文本框；对象 → JSON 文本域。
- 只读/不可编辑参数会禁用，不能勾选。
- 页面顶部显示「已选择 N 项」，保存时至少需要一项。
- **高级与状态选项**默认折叠在「高级与状态选项」中；**开发者/内部参数**默认隐藏，需打开「显示开发者/内部参数」开关。
- 参数下方的灰色小字是技术路径；如果 FDL 提供了条件表达式，会显示「条件：……」。
- **条件字段不会随上游选项实时显隐**。本版只展示条件文本，是否勾选由你判断；不要因为「界面上没消失」就认为条件已满足。

> 中文模式使用 ANSYS Fluent 汉化术语，英文模式使用 Fluent 原版字段名。开发者模式仍会显示 `boi_face_label_list` 这类真实内部 ID，不要改成自定义名称。

### 6.5 复合子任务（具名控制）

Add Local Sizing、Add Boundary Layers、Enclose Fluid Regions 等复合任务可以添加多个具名控制，例如同一模型上的 `wall-big` 与 `wall-small`。

操作：

1. 进入对应任务标签页。
2. 点 **添加复合子任务预设**。
3. 在卡片中填写 **子任务/控制名称**。该名称必须与目标模型里的标签/Zone/Region 名称一致，且同一任务内不能重复。
4. 勾选并填写该子任务的参数。
5. 需要多个控制时重复添加；每个卡片右上角可删除。

规则与提示：

- 名称是**模型相关**的，不能从参考工程照抄。参考工程里曾出现拼写错误 `wall-samll`，不要拿它当默认值。
- 部分参数（如 `local_settings_name`、`bl_control_name`）由应用自动写入控制名称，界面会提示「控制名称将自动写入 …」。不要手工再填一遍。
- 保存时若出现以下问题会阻止保存：
  - 子任务没填名称；
  - 同一任务内名称重复；
  - 子任务没有选择任何参数。
- 若几何导入前 Fluent 拒绝创建该子任务，界面会提示模板来自官方命令参数，应用时会在目标工作流中再次校验。

### 6.6 Watertight 的 11 个任务

| #   | 界面任务名           | 英文原名                        | 类型        | 应用时的行为                     |
| --- | -------------------- | ------------------------------- | ----------- | -------------------------------- |
| 1   | 导入几何             | Import Geometry                 | Simple      | **执行**：导入所选几何文件       |
| 2   | 添加局部尺寸         | Add Local Sizing                | Compound    | 只写参数/创建具名子任务，不执行  |
| 3   | 生成表面网格         | Generate the Surface Mesh       | Simple      | 只写参数，**不执行**（停线之一） |
| 4   | 描述几何             | Describe Geometry               | Conditional | 只写参数，不执行                 |
| 5   | 应用共享拓扑         | Apply Share Topology            | Simple      | 只写参数，不执行                 |
| 6   | 封闭流体区域（封盖） | Enclose Fluid Regions (Capping) | Compound    | 只写参数/创建具名子任务，不执行  |
| 7   | 更新边界             | Update Boundaries               | Simple      | 只写参数，不执行                 |
| 8   | 创建区域             | Create Regions                  | Simple      | 只写参数，不执行                 |
| 9   | 更新区域             | Update Regions                  | Simple      | 只写参数，不执行                 |
| 10  | 添加边界层           | Add Boundary Layers             | Compound    | 只写参数/创建具名子任务，不执行  |
| 11  | 生成体网格           | Generate the Volume Mesh        | Simple      | 只写参数，**不执行**（停线之一） |

> 第 3 与第 11 个任务就是「停线」。你可以在预设里设置它们的尺寸、体网格填充方式等参数，但应用不会点击它们。生成网格需要你在 Fluent 中手动继续。

### 6.7 保存时会发生什么校验

1. **界面级校验**：名称必填、至少一项、复合子任务命名与选择完整。
2. **预设结构校验**：后端按 schema 检查任务路径、参数路径、值类型与候选值。
3. **重名保护**：Meshing 预设名称在数据库中唯一。
4. 校验通过后保存为版本化 JSON，并记录工作流类型、Fluent 版本与状态（默认草稿）。

保存**不会**连接 Fluent，也**不会**校验目标模型里是否存在这些名称。名称校验发生在应用时——这是刻意的：预设要能跨同系列模型复用。

### 6.8 命名规范建议

- 同一系列模型使用**统一的命名约定**：边界、Face Zone、Region、局部尺寸标签都按同一规则命名。
- 名称**按原样填写**，注意大小写、连字符与下划线；不要用显示名代替真实标签名。
- 一个预设对应一个「命名一致的模型系列」，不要把不同命名规则的模型塞进同一个预设。
- 模型之间的差异（不同壁面、不同局部尺寸区域）用**多个具名子任务**表达，而不是改预设名称。
- 不要在预设里保留参考工程的拼写错误或临时名称；应用前用 Fluent 的标签/Zone 列表核对一遍。

### 6.9 设计建议

- **少即是多**：只勾选你确实要统一管理的参数；未勾选项保持 Fluent 当前值。
- **先小后大**：先做一个只含 2–3 项参数、1 个子任务的预设，跑通应用与回读，再扩充。
- **一个停线原则**：所有 Meshing 预设都应把生成表面/体网格留在 Fluent 里做；不要把本应用当成批量网格生成器。
- **用参考模型做对照**：创建时选一个参考模型，方便下次打开时知道这套预设面向哪类几何。

## 7. 实时应用 Meshing 预设

### 7.1 前置条件

- 目标几何或算例已导入 **我的模型**，且模型文件仍在原路径。
- 已有保存好的 Watertight Meshing 预设。
- 设置页的 Fluent Meshing 连接已保存；Fluent 路径正确、许可可用。
- launch 模式会启动新的 Fluent Meshing 会话；attach 模式会连接已保存的现有会话。

### 7.2 启动实时会话

1. 打开 **网格划分自动化**，在目标预设行点 ▶。
2. 在模型下拉框中选择一个或多个模型。支持批量选择。
3. 点 **应用并实时同步**。
4. Fluent AI 自动连接或启动 Fluent Meshing，并打开七步实时工作流页面。
5. 在第一步点击 **执行“导入几何模型”**，将当前选中的模型导入 Fluent Meshing。
6. 顶部显示当前模型进度、连接状态和每个模型的执行状态。

### 7.3 七步实时交互

- 点击任一步骤时，Fluent AI 把预设中属于该步骤的字段写入 Fluent，并立即回读全部字段。
- 预设未填写的字段显示 Fluent 当前值，可直接在面板中修改。
- 修改字段后约 650 ms 自动写回 Fluent，并逐字段回读。
- 面板每 2 秒轮询当前步骤。若 Fluent Meshing 原生界面修改了字段，面板会更新并标记「外部已修改」。
- 出现外部修改时不会静默覆盖；可保留新值，或点「用预设覆盖」重新写入本步预设。
- 点步骤底部的 **执行“…”** 会调用对应 PyFluent 工作流任务。成功后步骤标为已完成，并自动切换到下一步、自动写入下一步预设。
- 回退到已完成步骤时，该步骤重新变为当前步骤，后续完成状态会按校验规则重置。

### 7.4 多模型批量

- 当前模型的七步完成后，点 **处理下一个模型** 继续下一个模型；同一预设参数按相同规则应用。
- 单个模型失败不会阻止队列：可点 **重试当前模型**，也可直接处理下一个模型。
- 每个模型、每个步骤和每次 PyFluent 调用都记录在页面底部执行日志中。
- 日志包含命令阶段、写入/回读结果和异常；Fluent 原生 Console 仍在 Fluent 窗口中可查。

### 7.5 失败与恢复

| 现象                  | 含义                                       | 处理                                         |
| --------------------- | ------------------------------------------ | -------------------------------------------- |
| Fluent Meshing 未连接 | 启动失败、路径或许可问题                   | 检查设置页的 Fluent 路径、launch/attach 配置 |
| 几何导入失败          | 文件路径失效、格式不支持或 Fluent 导入报错 | 在「我的模型」刷新/重新导入后重试            |
| 参数写入失败          | 字段路径、子任务名称或类型不匹配           | 查看日志中的参数路径和 Fluent 返回信息       |
| 参数外部已修改        | 原生 Fluent 与 AI 面板发生并发修改         | 选择保留 Fluent 值或使用预设覆盖             |
| 步骤执行失败          | Fluent 工作流任务拒绝执行                  | 修正当前步骤参数后重试；必要时重试当前模型   |
| 连接中断              | Fluent 进程退出或端口失效                  | 点停止会话，回到设置页重新连接后再启动       |

> 实时会话没有跨步骤事务回滚。某一步失败后，已写入的前序参数仍会留在 Fluent 会话中；应修正问题后重试该步骤，或重试/切换模型。

## 8. 直接读取与写入

### 8.1 两种使用方式

- **界面诊断**（推荐日常使用）：设置 → Fluent Meshing 连接 → 连接与读写诊断。
- **HTTP API**（开发/集成）：`/api/meshing/read`、`/api/meshing/write` 等，需要每次启动的 bearer token；普通用户不需要直接调用。

### 8.2 诊断的语义

诊断不是「随便写一个值」：它读取代表参数，取其中一个已读到的值，把**同一个值**写回，再回读确认。因此它不会改变参数语义，只验证链路。

它适合：

- 新环境首次连接后的连通性确认。
- 升级 Fluent/PyFluent 后确认读写接口仍可用。
- 排查「能连接但读不到参数」的问题。

它不适合：

- 校验你的预设名称是否存在（请用应用预设）。
- 批量修改参数（请用预设）。
- 需要回滚保证的写入（诊断只写同值；直接写接口没有快照回滚）。

### 8.3 会读写哪些参数

见 4.4 的代表参数表。诊断只覆盖少量字段，不会枚举全部 427 项；它成功不代表所有参数都可写。

### 8.4 结果解读

- 三个数字都正常：任务数 > 0、读取项 > 0、写入回读项 > 0。
- 如果「发现任务」有值但读取项为 0：可能是工作流未初始化、attach 模式限制或 schema 与 Fluent 版本不匹配。
- 如果读取成功但写回失败：看错误消息；常见是只读参数、值类型不匹配、attach 限制。

### 8.5 直接写的边界

- 写入默认带 `verify: true`，逐项回读；不一致会标记失败。
- 直接写接口**不提供快照与回滚**；失败时已写入的项可能保留。
- attach 模式下读取失败会阻断写入，避免部分写入。
- 所有 Meshing 会话操作串行化到单线程执行器；不要并发调用读写。
- 直接写不会执行任务，也不会生成网格；它只改参数状态。

### 8.6 给开发/集成人员的接口摘要

| 方法 | 路径                                   | 用途                                                   |
| ---- | -------------------------------------- | ------------------------------------------------------ |
| GET  | `/api/meshing/status`                  | 连接状态、版本、PID、host/port                         |
| POST | `/api/meshing/connect`                 | 启动或附加 Meshing 会话                                |
| POST | `/api/meshing/disconnect`              | 断开                                                   |
| POST | `/api/meshing/read`                    | 读取指定项；`items` 为空时读取当前 schema 全部叶子参数 |
| POST | `/api/meshing/write`                   | 写入并可选回读                                         |
| GET  | `/api/meshing/schemas`                 | 可用工作流摘要                                         |
| GET  | `/api/meshing/schemas/{workflow_type}` | 完整任务/参数 schema                                   |
| POST | `/api/meshing/presets/validate`        | 预设结构校验                                           |

请求示例（仅供理解结构）：

```json
{
  "workflow_type": "watertight",
  "verify": true,
  "items": [
    {
      "task_path": ["create_surface_mesh"],
      "argument_path": ["cfd_surface_mesh_controls", "max_size"],
      "compound_child_name": null,
      "value": 0.002,
      "required": true
    }
  ]
}
```

> 所有 `/api/*` 端点都需要 `Authorization: Bearer <token>`。令牌由主进程在每次启动时随机生成，不暴露给渲染进程，也不建议写入脚本或共享给他人。

## 9. Solver 自动化接口（界面板块已移除）

本版已从桌面界面移除「我的自动化」板块及其 `/automations` 页面入口。Solver 自动化的数据库表、仓储与后端 API 仍保留，供内部集成和后续功能使用；普通用户不再能在界面中应用、编辑、复制或删除 Solver 预设，也不再查看其最近会话和同步日志。

## 10. 任务、进度与取消

### 10.1 在哪里看

顶部「任务」徽标显示活动任务数量；点击展开任务列表（最多 20 条）。每 2 秒自动刷新。

### 10.2 状态与阶段

| 状态   | 含义                                    |
| ------ | --------------------------------------- |
| 排队中 | 已创建，等待执行                        |
| 运行中 | 正在执行；进度条显示阶段百分比          |
| 已成功 | 全部步骤完成并通过回读                  |
| 已失败 | 任一阶段异常；消息/错误可在任务详情查看 |
| 已取消 | 用户在阶段之间取消                      |

Solver 应用的典型进度：5%（加载）→ 30%（连接）→ 55%（载入算例）→ 70%（写入与回读）→ 100%。Meshing 应用：5% → 30%（连接）→ 55%（导入与名称校验）→ 100%。

### 10.3 取消的边界

- 取消是**协作式**的：任务在阶段边界检查取消标记；正在执行的单次 Fluent 调用（例如一次导入或一次写入）不会被打断。
- 因此点击取消后，任务可能还会停留一段时间；不要连点，也不要强制结束进程。
- 取消后作业状态变为「已取消」；已执行的 Fluent 操作不会自动撤销。

### 10.4 任务卡住时

1. 先看顶部任务详情里的最后一条消息，判断卡在哪个阶段。
2. 若是 Fluent 启动/导入/写入，通常是 Fluent 侧耗时或许可等待；给它时间。
3. 若是侧车异常（消息含连接失败/超时），到设置页重启侧车。
4. 仍无响应时，取消任务；再断开 Fluent，重新连接后重试。
5. 不要在同一会话上并发发起第二个应用；会话操作是串行的，第二个任务会排队。

## 11. 数据备份与恢复

### 11.1 数据在哪里

| 内容              | 路径                                        |
| ----------------- | ------------------------------------------- |
| 主数据库          | `%APPDATA%\fluent-ai\data\fluent-ai.db`     |
| 备份目录          | `%APPDATA%\fluent-ai\data\backups\`         |
| 界面缓存/本地状态 | `%APPDATA%\fluent-ai\`（Electron 用户数据） |
| 应用日志          | 仅控制台输出，本版不写轮转日志文件          |

> 数据库使用 SQLite（WAL 模式）。不要在应用运行时用外部工具直接改写数据库；需要迁移时先退出应用。

### 11.2 自动与手动备份

- **每日自动**：侧车启动时，如果备份目录里最新备份超过 24 小时，自动创建一份 `daily` 备份。
- **手动**：设置 → 数据安全 → **立即备份**。
- **保留数量**：最多 10 份，超出后按时间删除最旧的。
- **完整性**：每份备份写入后执行 `PRAGMA integrity_check`，失败会删除该备份并报错。
- **恢复前安全备份**：每次恢复前自动创建 `pre-restore` 备份。

设置页列出最近 5 份备份（名称、时间、大小），可点「刷新」重新加载。

### 11.3 恢复步骤

1. 断开 Fluent 连接，确认没有运行中的任务。
2. 打开 **设置 → 数据安全**，在列表中找到目标备份。
3. 点 **恢复**，在确认框中确认。系统会先创建 `pre-restore` 备份，再校验目标备份完整性，最后覆盖当前数据库。
4. 成功后提示「数据库已恢复，并已创建恢复前安全备份」。
5. 建议重启应用，确保所有页面重新读取数据。

> 恢复会覆盖当前数据库内容。恢复后，恢复前的那份数据只保存在 `pre-restore` 备份里；需要找回时再用它恢复一次。

### 11.4 迁移到另一台机器

1. 退出 Fluent AI。
2. 复制整个 `%APPDATA%\fluent-ai\data\` 目录（包含 `backups\`）。
3. 在新机器安装同版本应用，先启动一次再退出。
4. 用复制过来的 `data\` 覆盖新机器的同名目录。
5. 启动应用，检查预设、模型路径与备份列表。模型路径是绝对路径，换机器后可能需要重新导入。

### 11.5 卸载时的数据

卸载器默认保留应用数据。若要把机器交给他人，请先备份需要的内容，再手动删除 `%APPDATA%\fluent-ai`。

## 12. 故障排查

### 12.1 通用排查顺序

1. 看右上角侧车徽标：是否「已就绪」；异常时先点「重启侧车」。
2. 看任务徽标的最后一条消息，确定失败阶段。
3. 看是否弹出了具体错误（名称缺失、连接失败、回读不一致）。
4. 回到设置页确认 Fluent 路径、连接模式、host/port。
5. 仍无法定位时，重启应用；再不行，重启机器后重试。

### 12.2 常见故障

| 现象                                                     | 可能原因                                       | 处理                                                         |
| -------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 侧车一直「启动中」或变「异常」                           | 冷启动预加载慢、端口/权限、Python 运行时异常   | 等待 60 秒；点「重启侧车」；仍失败则重启应用                 |
| 页面显示「桌面桥不可用」                                 | 在普通浏览器里打开了页面，而不是 Electron 应用 | 从桌面/开始菜单启动 Fluent AI                                |
| 连接 Fluent 失败/超时                                    | 路径错误、版本不符、许可不可用、已有会话冲突   | 核对 `fluent.exe`；确认 2025 R2 与许可；关闭冲突会话；重试   |
| 连接 Meshing 成功但读写报 `StringVector is not iterable` | attach 模式限制                                | 改用「启动新会话」；attach 只用于连接/状态                   |
| 应用 Meshing 预设提示缺失名称                            | 目标几何没有这些标签/Zone/Region               | 在 Fluent 中核对真实名称；改预设或改几何命名；不要用模糊匹配 |
| 导入 `.dsco` 卡住                                        | 独立 Fluent Meshing 直连 `.dsco` 可能阻塞      | 改用在 Workbench 生成的 `.pmdb`                              |
| Fault-tolerant 某任务没有参数                            | 两个复合任务受 PyFluent `RecursionError` 限制  | 该任务暂不可用；不要猜字段；用 Fluent 手工完成这部分         |
| 应用成功但没生成网格                                     | 这是设计行为                                   | 在 Fluent 中继续 Generate Surface/Volume Mesh                |
| 回读不一致                                               | 单位/类型/候选值不符，或参数条件未满足         | 在 Fluent 中查看当前值；修正预设；必要时重开会话             |
| 任务长时间「运行中」                                     | Fluent 导入/写入耗时；取消只在阶段边界生效     | 看消息与进度；耐心等待；必要时取消并重连                     |
| 安装时 SmartScreen 警告                                  | 安装包未签名                                   | 核对 SHA-256；「更多信息 → 仍要运行」；企业环境请用签名版本  |
| 恢复备份后列表不对                                       | 恢复的是旧数据；或恢复时仍有任务在跑           | 确认备份时间；断开连接、停止任务后重试；重启应用             |
| 模型打不开/找不到文件                                    | 源文件被移动、改名或删除                       | 重新导入模型；模型库只引用不复制                             |

### 12.3 错误信息对照

| 错误片段                                | 含义                                      | 动作                                                 |
| --------------------------------------- | ----------------------------------------- | ---------------------------------------------------- |
| `Missing required Meshing names: …`     | 名称校验未通过，写入前中止                | 按列出的 `类型:名称` 修预设或几何命名                |
| `Meshing task path was not found`       | schema 中的任务路径在当前 Fluent 上不存在 | 确认 Fluent 版本；重新加载 schema；不要手改预设 JSON |
| `Fluent Meshing is not connected`       | 会话未连接或已失效                        | 回设置页连接；检查是否被外部关闭                     |
| `Meshing readback did not match`        | 写入值与回读值不一致                      | 检查单位/类型；在 Fluent 中看当前值                  |
| `Could not create compound child for …` | 子任务创建失败（名称/参数/API 限制）      | 检查名称是否重复、参数是否完整；重开会话重试         |
| `RecursionError`                        | PyFluent 提取该复合任务参数时递归爆栈     | 该任务不可用；不要绕过                               |
| `TimeoutError` / 启动超时               | Fluent 未在 300 秒内就绪                  | 检查许可、路径、机器负载；重试                       |
| `FileNotFoundError` / 几何不存在        | 模型路径失效                              | 重新导入几何                                         |

> 部分后端错误消息是英文，界面会原样显示；这不影响判断。先看错误里的名称与阶段，再按上表处理。

## 13. 能力边界与已知限制

### 13.1 功能边界

- **不做网格生成**：只到生成表面/体网格之前。
- **不保存工程**：不写 `.wft`、`.cas`、`.h5`；需要保存请在 Fluent 中操作。
- **名称精确匹配**：任何缺失即中止，不做模糊匹配、不静默改名。
- **只校验导入后可见的名称**：只在生成表面网格后才出现的名称，按「不生成网格」原则无法预先校验，会被拒绝。
- **Solver 覆盖有限**：39 项静态设置 + 加载算例后动态发现的材料与部分边界字段；不是 Fluent 全量设置。
- **没有三维视口**：几何/网格检查在 Fluent 中完成。
- **模型只引用不复制**：源文件移动/删除会导致失败。
- **单会话串行**：所有 Fluent/Meshing 操作走单线程执行器，不支持并发写同一会话。

### 13.2 兼容性

- 仅验证 Fluent 2025 R2 / 25.2.0；应用固定使用 `25.2.0` 连接配置。
- Meshing schema 与 FDL 元数据来自 2025 R2；换版本可能出现任务/参数路径不一致。
- Meshing attach 在 2025 R2 上受 PyFluent 0.42.1 限制，不能读写。
- Fault-tolerant 的 `Identify Construction Surfaces`、`Create Local Refinement Regions` 参数不可用（`RecursionError`）。
- 直接 `.dsco` 导入可能阻塞；优先 `.pmdb`。

### 13.3 数据与安全

- 侧车只监听 `127.0.0.1`，每次启动随机端口 + 一次性 bearer token；不对外网开放。
- 渲染进程开启 `contextIsolation`/`sandbox`、关闭 `nodeIntegration`；文件选择与凭据由主进程处理。
- Fluent 凭据使用 Electron `safeStorage` 加密保存，但**当前 attach 流程尚未消费该密码**；设置页只显示可用/已配置状态，没有密码编辑入口。
- 模型选择令牌只在内存中，应用重启后失效。
- 所有业务数据在本机 SQLite 中；没有云端同步。

### 13.4 界面与体验

- 界面语言可在设置中切换为中文或英文，并会持久保存。
- 条件字段不随上游选项实时显隐，只显示条件文本；需要你判断条件是否满足。
- 开发者/内部参数默认隐藏，打开开关后可见。
- Meshing 预设列表页提供创建、编辑、应用、删除和刷新；当前没有复制入口。
- 任务取消是协作式的，不能打断正在执行的单次 Fluent 调用。
- Meshing 直接写接口没有快照/回滚。
- Solver 失败回滚是尽力而为，不保证原子性。

### 13.5 安装与发布

- 当前安装包未做 Authenticode 签名，Windows 可能提示 SmartScreen。
- 安装包内置 Python 运行时与依赖，体积较大（安装后约 360 MiB）。
- 应用日志仅控制台输出，没有轮转日志文件；排查时优先看界面消息与任务/同步日志。

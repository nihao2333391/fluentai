## 1. 30 秒快速开始

第一次使用时按下面顺序操作：

1. 安装并启动 Fluent AI，等待顶部状态显示 **FastAPI 侧车 · 已就绪**。
2. 打开 **设置 → Fluent Meshing 连接**。
3. 选择 **启动新会话**，填写 `fluent.exe` 路径，建议选择 **显示 GUI**。
4. 点击 **保存连接设置**，再点击 **连接**。
5. 点击 **连接与读写诊断**，确认任务树、参数读取和回读验证都成功。
6. 打开 **我的模型 → 导入模型**，导入一个 `.pmdb`、`.scdoc`、`.scdocx` 或 `.dsco` 模型。
7. 打开 **网格划分自动化 → 创建网格划分自动化**，选择 **水密几何**，按七步填写需要预置的参数并保存。
8. 回到自动化列表，点击行末 **应用**，勾选一个或多个同类模型，再点击 **应用并实时同步**。
9. 在实时工作流页面逐节点检查参数，点击 **执行当前步骤**。成功后应用会自动进入下一步。
10. 多模型任务中，当前模型完成后点击 **下一个模型**，同一预设会继续应用。

推荐的首次验收顺序：

- 先用一个模型、一个最小预设跑通。
- 确认名称、单位和文件路径都正确。
- 再启用多模型批量。
- 执行表面网格或体网格前先确认 Fluent 中的几何和尺寸设置。

## 2. 产品定位与安全边界

### 2.1 Fluent AI 解决什么问题

Fluent AI 把 Fluent Meshing 中重复的设置保存为可复用预设，并把这些预设写入真实的 Fluent Meshing 会话。应用重点解决：

- 同类模型重复点选参数；
- 多模型批量应用同一套 Meshing 规则；
- 参数写入后逐项回读验证；
- Fluent AI 与 Fluent 原生界面之间的参数同步；
- 七步 Watertight 工作流的执行状态和日志追踪；
- 模型、预设、作业与同步记录的统一管理。

### 2.2 本机架构

```text
React + Ant Design 界面
        ↓ Electron 安全 IPC
Electron 主进程
        ├─ 启动并监管 FastAPI 侧车
        ├─ 原生模型文件选择
        ├─ 数据库与备份路径管理
        └─ 本地凭据安全存储
        ↓ 127.0.0.1 + 随机端口 + 临时令牌
FastAPI 侧车
        ├─ 模型、自动化、设置、作业、同步日志
        ├─ 单线程 Fluent 操作队列
        ├─ SQLite 数据库
        └─ PyFluent
        ↓
ANSYS Fluent / Fluent Meshing 2025 R2
```

侧车只监听本机回环地址，不对外开放端口。Fluent AI 不会上传模型、网格或数据库到云端。

### 2.3 必须理解的安全边界

- **执行网格任务会真实修改 Fluent 会话。** “执行当前步骤”不是预览按钮；表面网格、边界层和体网格任务会在 Fluent 中实际运行。
- **预设名称必须与目标模型一致。** 局部尺寸标签、边界标签、Region 名称等不做模糊匹配。
- **错误设置可能覆盖 Fluent 当前值。** 应用会在写入后回读，但不能替代工程师检查。
- **Fluent 不提供跨任务事务。** 某一步失败后，前面的步骤可能已经生效。
- **应用不自动保存最终网格文件。** 需要在 Fluent 中自行保存 `.msh`、`.cas` 或项目文件。
- **执行前建议备份数据库。** 设置页提供手动备份和每日自动备份。

## 3. 环境要求与安装

### 3.1 环境要求

| 项目     | 要求                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 操作系统 | Windows 10/11 x64                                                                |
| ANSYS    | Fluent 2025 R2 / 25.2.0                                                          |
| 许可     | Fluent Meshing 可用，并具备 Discovery/SpaceClaim 读取许可（使用 CAD 格式时需要） |
| 内存     | 建议至少 16 GB；体网格任务建议 32 GB 以上                                        |
| 磁盘     | 安装包约 170 MB，安装后约 650 MB；Fluent 临时文件和网格需要额外空间              |
| 网络     | 仅连接本机 Fluent，不需要云端服务                                                |

### 3.2 安装包信息

当前 Windows 安装包：

```text
FluentAI-0.1.0-x64-Setup.exe
```

当前构建 SHA-256：

```text
03eda593d2c662149acf7fb5dfc799b67793bd9c50f6b9ffcf27ded449e65ec9
```

安装前建议在 PowerShell 中校验：

```powershell
Get-FileHash .\FluentAI-0.1.0-x64-Setup.exe -Algorithm SHA256
```

安装包当前未配置 Authenticode 证书，Windows SmartScreen 可能显示“未知发布者”。请先向项目维护者确认来源并核对 SHA-256。

### 3.3 安装步骤

1. 关闭旧版 Fluent AI 和正在运行的 Fluent Meshing 会话。
2. 运行安装包。
3. 选择安装目录。默认安装到当前用户目录，不要求管理员权限。
4. 安装完成后从桌面快捷方式或开始菜单启动。
5. 首次启动会创建本地数据目录和数据库。
6. 等待顶部显示 **FastAPI 侧车 · 已就绪**。

### 3.4 数据目录

默认路径为：

```text
%APPDATA%\fluent-ai\data
```

数据库备份目录为：

```text
%APPDATA%\fluent-ai\data\backups
```

模型文件默认只保存路径引用，不复制到应用目录。移动、重命名或删除源模型后，需要重新导入或刷新模型记录。

## 4. 首次启动与界面总览

### 4.1 侧车状态

顶部状态徽标用于判断应用是否可以使用：

| 状态   | 含义                           | 操作                       |
| ------ | ------------------------------ | -------------------------- |
| 已就绪 | FastAPI 侧车已启动，数据库可用 | 可以开始操作               |
| 启动中 | 应用正在启动 Python 侧车       | 等待 10–30 秒              |
| 异常   | 侧车退出、端口失败或数据库异常 | 点击重启侧车，查看错误信息 |
| 未启动 | 侧车尚未运行                   | 点击重启侧车或重新启动应用 |

### 4.2 左侧导航

当前主界面包括：

- **工作区 → 我的模型**：导入、查看和打开模型。
- **工作区 → 网格划分自动化**：创建、编辑、删除和应用 Meshing 预设。
- **系统 → 设置**：主题、语言、Fluent 连接、Meshing 连接和数据备份。

### 4.3 语言与主题

- 中文：界面术语与 ANSYS Fluent 汉化版保持一致。
- English：界面术语与 ANSYS Fluent 原版保持一致。
- 主题：浅色、深色或跟随系统。
- 语言和主题会保存在本机。

英文界面中的 ANSYS 原始术语（例如 `Generate the Surface Mesh`）不会翻译成自创名称。

## 5. 设置与连接

### 5.1 Fluent 连接

用于模型打开和 Solver 侧的基础连接。

| 字段              | 说明                                                               |
| ----------------- | ------------------------------------------------------------------ |
| 连接模式          | **启动新会话** 或 **连接现有会话**                                 |
| Fluent 可执行文件 | 例如 `D:\Ansys2025R2\ANSYS Inc\v252\fluent\ntbin\win64\fluent.exe` |
| 主机              | 启动模式通常为 `127.0.0.1`；附加模式填写现有会话主机               |
| 端口              | 附加模式需要现有 Fluent 的 gRPC 端口                               |
| 连接状态          | 显示已连接/未连接                                                  |

### 5.2 Fluent Meshing 连接

Meshing 自动化使用独立的 Meshing 会话配置。

| 字段             | 建议                                              |
| ---------------- | ------------------------------------------------- |
| 网格划分工作流程 | Watertight Geometry 或 Fault-tolerant Meshing     |
| 网格划分会话模式 | 首次使用建议选择 **显示 GUI**                     |
| 后台运行         | 适合熟练用户和批量任务，不便于人工检查原生界面    |
| 连接模式         | 优先 **启动新会话**；附加模式受 PyFluent 版本限制 |

> 当前版本的 Meshing 附加模式可能只能建立连接，无法完整读取工作流参数。要验证读写和实时同步，请使用“启动新会话”。

### 5.3 推荐连接流程

1. 填写 `fluent.exe` 路径。
2. 选择“启动新会话”。
3. 选择“显示 GUI”。
4. 点击“保存连接设置”。
5. 点击“连接”。
6. 点击“连接与读写诊断”。
7. 只有诊断通过后再创建或应用 Meshing 自动化。

### 5.4 连接与读写诊断会检查什么

- 能否启动或连接 Fluent Meshing；
- 能否取得工作流对象；
- 能否读取真实任务树和参数；
- 能否写入一个代表性参数；
- 写入后能否回读一致；
- 连接关闭是否干净。

### 5.5 连接失败检查清单

- `fluent.exe` 路径是否存在。
- ANSYS 许可服务是否启动。
- Fluent 版本是否为 2025 R2。
- 是否有旧 Fluent 进程占用端口或文件。
- 是否选择了正确的 GUI/后台模式。
- 连接设置是否已经保存。
- 模型路径中是否包含无法访问的网络盘或已删除目录。

## 6. 我的模型

### 6.1 导入模型

1. 打开 **我的模型**。
2. 点击 **导入模型**。
3. 使用系统文件选择器选择模型。
4. 应用会校验文件存在、不是空文件、扩展名受支持。
5. 导入成功后记录模型名称、路径、大小和时间。

### 6.2 支持的模型格式

**Fluent 算例/网格：**

- `.cas`
- `.cas.h5`
- `.msh`
- `.msh.h5`

**CAD/几何：**

- SpaceClaim/Discovery：`.scdoc`、`.scdocx`、`.dsco`
- STEP：`.step`、`.stp`、`.stpz`
- IGES：`.iges`、`.igs`
- JT：`.jt`
- 3D XML：`.3dxml`
- CATIA：`.catpart`、`.catproduct`
- SolidWorks：`.sldprt`、`.sldasm`
- Inventor：`.ipt`、`.iam`
- Creo/ProE/NX 常见后缀：`.prt`、`.asm`
- Parasolid：`.x_t`、`.x_b`
- ACIS：`.sat`、`.sab`
- 中性/网格几何：`.par`、`.stl`、`.pmdb`、`.fmd`、`.tgf`

导入格式受支持不等于该格式一定适合 Watertight 工作流。推荐顺序：

1. `.pmdb`
2. 原生 `.scdoc` / `.scdocx` / `.dsco`
3. `.step` / `.stp`
4. 其他 B-Rep CAD 格式

### 6.3 格式兼容性说明

- **`.scdoc` / `.scdocx` / `.dsco`**：由 Fluent 启动 Discovery 读取，可保留有业务含义的命名选择。
- **`.pmdb`**：Fluent Meshing 原生数据库，通常最稳定，推荐用于批处理。
- **STEP**：几何可导入，但实测可能丢失 `inlet-cold`、`outlet`、`wall-big` 等命名选择。
- **`.fmd` / `.tgf`**：属于 faceted 格式，Watertight 的 Import Geometry 节点可能明确拒绝；Fault-tolerant 工作流使用 FMD 更合适。
- **`.stl`**：适合面网格/几何交换，但不应依赖其保留 CAD 名称。

### 6.4 模型只保存路径引用

Fluent AI 不会复制或移动模型文件。若文件被移动、重命名或所在网络盘断开，原本保存的自动化应用会失败。建议：

- 将模型放在固定本地目录；
- 使用英文路径或确认中文路径可被 Fluent 正确读取；
- 变更路径后重新导入模型。

### 6.5 在 Fluent 中打开模型

模型列表中的打开按钮用于将算例/网格载入 Solver 侧 Fluent。Meshing 自动化的几何导入由实时工作流页面执行，不由该按钮替代。

## 7. 创建网格划分自动化

### 7.1 自动化预设是什么

网格划分自动化是一组“任务路径 + 参数路径 + 目标值”的集合。它不是模型副本，也不是固定网格模板。

一个预设可包含：

- 顶部基本信息：名称、参考模型、描述、工作流类型；
- 七步 Watertight 参数；
- 多个局部尺寸具名控制；
- 多个边界层具名控制；
- 高级与内部参数；
- 预设项计数和选中状态。

### 7.2 创建步骤

1. 打开 **网格划分自动化**。
2. 点击 **创建网格划分自动化**。
3. 填写名称，例如“文丘里系列-标准水密网格”。
4. 选择参考模型和模型类别。
5. 选择 **水密几何** 或 **容错网格划分**。
6. 在顶部七步条中选择一个步骤。
7. 按需勾选或填写该步骤参数。
8. 对局部尺寸和边界层添加独立具名控制。
9. 检查右上角“已选择 N 项”。
10. 点击保存。

### 7.3 参数填写原则

- 参数没填时不要假设为 Fluent 默认值；运行时会读取 Fluent 当前值。
- 下拉框值来自 Fluent 2025 R2 schema，不要手工创造枚举值。
- 数值单位必须与模型单位一致。
- 同一预设只应复用于同一模型系列和相同命名规则。
- 复合子任务名称必须与模型标签完全一致。

### 7.4 显示开发者/内部参数

“显示开发者/内部参数”用于展开高级、内部和调试字段。普通用户只应编辑已验证字段。开发参数可能因 Fluent 版本变化，不应直接用于生产预设。

### 7.5 编辑和复制

- 已保存的自动化可以从列表进入编辑。
- 修改后保存会覆盖原预设。
- 可复制现有预设作为同类模型的新模板。
- 删除自动化只删除预设和关联记录，不删除模型文件。

## 8. 七步 Watertight 工作流

Fluent AI 的实时页与 Fluent Meshing Watertight Geometry 工作流按以下顺序对齐：

| 序号 | 步骤             | 主要作用                                   |
| ---- | ---------------- | ------------------------------------------ |
| 1    | 导入几何结构     | 选择文件、单位、导入选项并执行导入         |
| 2    | 添加局部尺寸     | 按标签或选择范围设置局部网格尺寸           |
| 3    | 生成表面网格     | 计算表面网格尺寸场并生成面网格             |
| 4    | 描述几何结构     | 选择流体/固体区域类型和共享拓扑策略        |
| 5    | 更新区域类型设定 | 检查和修改 Region 的 fluid/solid 类型      |
| 6    | 添加边界层       | 设置边界层数量、增长率、过渡方式和目标标签 |
| 7    | 生成体网格       | 设置体网格方法并生成最终体网格             |

### 8.1 顶部步骤条

- 当前步骤高亮；
- 已完成步骤显示 ✓；
- 运行中显示加载状态；
- 失败显示告警图标；
- 窗口较窄时步骤条可横向滚动。

### 8.2 子项与具名控制

局部尺寸和边界层支持添加多个具名控制：

- 局部尺寸示例：`wall-big`、`wall-small`。
- 边界层示例：`smooth-transition_1`、`smooth-transition_2`。
- 名称必须与模型中的标签、Face Zone 或 Region 一致。
- 同一任务下名称不能重复。
- 每个具名控制至少要选择一项参数。

### 8.3 名称校验

应用会在写入前检查：

- 名称是否存在于导入后的 Fluent Meshing 模型；
- 是否缺少目标标签；
- 是否重复创建同名控制；
- 选择的参数是否有效。

校验失败时不会继续后续步骤。应先回到 CAD 或 Fluent 中修正名称，再重新导入。

## 9. 应用自动化与实时同步

### 9.1 启动实时会话

1. 在 **网格划分自动化** 列表中选择预设。
2. 点击行末 **应用**。
3. 勾选一个或多个几何模型。
4. 点击 **应用并实时同步**。
5. Fluent AI 保存当前连接配置并启动或复用 Fluent Meshing。
6. 打开实时工作流页面。
7. 等待连接状态显示 **Fluent Meshing 已连接**。

如果启动超时：

- 检查 Fluent 路径；
- 检查许可；
- 检查模型路径；
- 检查是否选择了后台模式导致 Fluent GUI 无法显示；
- 关闭残留 Fluent/Discovery 进程后重试。

### 9.2 执行第一步：导入几何

1. 当前步骤应为 **导入几何结构**。
2. 检查文件名、单位、导入类型和高级选项。
3. 点击 **执行当前步骤**。
4. 等待 Fluent Console 输出导入完成。
5. 导入成功后步骤条出现 ✓，并切换到添加局部尺寸。

导入阶段通常最容易暴露：

- CAD 格式不受支持；
- Discovery Reader 无法启动；
- 模型路径无权限；
- 命名选择丢失；
- 文件为空或损坏。

### 9.3 执行后续步骤

进入每个步骤时，Fluent AI 会：

1. 把预设中该步骤已配置的值写入 Fluent；
2. 立即从 Fluent 回读；
3. 在右侧参数面板显示当前生效值；
4. 将未配置字段显示为 Fluent 当前值。

点击 **执行“步骤名”** 后：

- Fluent 真正执行该任务；
- Console 输出进入执行日志；
- 成功后步骤自动打 ✓；
- 自动进入下一步；
- 失败时步骤变红并保留错误信息。

### 9.4 双向同步

- **AI → Fluent：** 修改右侧参数后，应用在短暂延迟后写入 Fluent。
- **Fluent → AI：** 应用轮询当前步骤参数，读取原生界面中的修改。
- **冲突处理：** 外部修改会被标记；可以点击 **重新写入本步预设** 覆盖 Fluent 当前值。
- 参数写入后会再次回读，避免界面显示与实际值不一致。

### 9.5 回退与重编辑

已完成的步骤允许点击回退查看或修改。回退后：

- 当前步骤重新进入可编辑状态；
- 后续步骤状态会根据执行结果重新校验；
- 对已经运行的网格任务重新执行可能覆盖当前网格结果。

### 9.6 停止会话

点击 **停止会话** 会结束实时同步并断开 Fluent Meshing。停止前请确认：

- 网格文件已经保存；
- 当前任务已经完成；
- 没有需要保留的临时几何或 Region 修改。

## 13. 故障排查

### 13.1 侧车异常

错误示例：

```text
Sidecar exited before readiness (code=1, signal=null)
Error invoking remote method ... HTTP 500
```

处理顺序：

1. 点击顶部 **重启侧车**。
2. 查看侧车错误详情。
3. 检查数据目录是否可写。
4. 检查安全软件是否拦截 Python 进程。
5. 检查安装目录是否完整。
6. 用设置页恢复最近一次数据库备份。
7. 仍失败时重新安装应用。

### 13.2 Fluent 路径或许可问题

- 使用完整 `fluent.exe` 路径；
- 确认 ANSYS 许可服务正在运行；
- 确认 Fluent 版本与文档匹配；
- 关闭无法正常退出的旧 Fluent 会话；
- 不要在 GUI 和后台模式之间频繁切换同一会话。

### 13.3 `.scdoc` / `.scdocx` / `.dsco` 导入超时

Fluent 会启动 Discovery 读取 SpaceClaim 文件，并等待 `.plugin` 握手。若日志出现：

```text
Timeout reached, failed to start Discovery!
```

但手工启动 Discovery 可以成功，常见原因是 **Windows 计算机名与 Python/DNS 主机名不一致**。

检查：

```powershell
Write-Output $env:COMPUTERNAME
[System.Net.Dns]::GetHostName()
```

若两个名称不同，可在当前用户临时目录建立目录联接。此操作不修改 ANSYS 安装：

```powershell
$root = Join-Path $env:TEMP 'Ansys\RunningCADs'
$dnsName = [System.Net.Dns]::GetHostName()
$computerName = $env:COMPUTERNAME
$expected = Join-Path $root $dnsName
$actual = Join-Path $root $computerName

New-Item -ItemType Directory -Force -Path $root, $actual | Out-Null

if (
  $dnsName -ne $computerName -and
  -not (Test-Path -LiteralPath $expected)
) {
  New-Item -ItemType Junction -Path $expected -Target $actual | Out-Null
}
```

然后关闭残留 Fluent/Discovery，重新执行导入。验证时 Fluent 日志应直接显示命名选择，例如：

```text
processing named selection 'inlet-cold'
processing named selection 'outlet'
processing named selection 'wall-big'
```

如果仍然超时：

- 确认 ANSYS 的 Discovery/SpaceClaim Reader 已正确安装；
- 确认当前用户对临时目录有写权限；
- 检查 `CAD Configuration Manager`；
- 如仅需完成当前任务，可先导入已生成的 `.pmdb`。

### 13.4 命名选择丢失

优先使用：

1. `.pmdb`
2. 原生 `.scdoc` / `.scdocx` / `.dsco`

STEP 或其它中性格式可能只保留几何，不保留命名面。重新导出 STEP 不等于恢复命名选择。

### 13.5 应用界面中英文混乱

打开 **设置 → 界面语言**：

- 中文：与 ANSYS Fluent 汉化术语对齐；
- English：与 ANSYS 原版术语对齐。

切换后仍显示旧文本时，返回上一页再进入，或重启应用。

### 13.6 安装包安全提示

当前安装包未签名，SmartScreen 可能提示。处理方式：

- 核对 SHA-256；
- 只从项目维护者提供的可信位置下载；
- 正式团队交付时配置 Authenticode 证书后重新构建。

## 15. 能力边界与已知限制

- 当前主要支持 ANSYS Fluent 2025 R2。
- Watertight 实时工作流覆盖七步主流程；Fault-tolerant 的参数编辑与部分实时能力仍在持续验证。
- 附加模式的 Meshing 参数读取受 PyFluent 版本限制，生产验证优先使用启动新会话。
- PyFluent 对个别 Fault-tolerant 任务存在已知限制。
- 参数 schema 来自本机 Fluent 版本；升级 ANSYS 后必须重新验证。
- Fluent 执行网格任务后没有统一撤销，失败恢复依赖 Fluent 状态和备份流程。
- 安装包尚未 Authenticode 签名。
- 模型文件不复制到应用目录，路径迁移需要人工处理。
- 应用不自动保存最终网格；请在 Fluent 中明确保存。
- 当前没有云端同步和远程多用户数据库。

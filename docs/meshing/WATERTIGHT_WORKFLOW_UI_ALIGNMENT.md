# Fluent 2025 R2 水密工作流界面与两阶段生成

## 目标与依据

模板只保存用户修改的参数。应用模板时，平台导入目标几何、自动准备面网格前设置，等待用户检查并点击“生成面网格”；随后自动准备体网格前设置，等待用户检查并点击“生成体网格”。准备阶段不得生成面网格或体网格。

依据：`docs/meshing/ui-audit/MESHING_UI_FULL_AUDIT.md`、`docs/meshing/fluent-meshing-25.2-watertight.schema.json`、Fluent 2025 R2 安装目录的 `Meshing.fdl`，以及 [Ansys 水密工作流说明](https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/flu_ug/tgd_user_workflow_guided_watertight.html)。本文件将代码检查与 Fluent 实机检查分别记录。

## 现状、问题和实施状态

| 功能 | 实施前 | 目标与实现位置 | 状态 |
| --- | --- | --- | --- |
| 导入目标几何 | 导入完成后只更新步骤索引 | 导入成功后主动准备局部尺寸与面网格参数；下一文件也自动导入 | 已实现，队列步骤待 API 集成验证 |
| 局部尺寸写入 | 首次写入依赖 Fluent 当前任务事件 | 导入后主动写入、校验并执行已配置的局部尺寸；任务事件只观察状态 | 已实现，真实 Fluent 子项行为待验证 |
| 面网格检查关口 | 缺少阶段状态与专用按钮 | 参数准备成功显示就绪；仅专用操作生成面网格 | 已实现，自动化阶段测试通过 |
| 体网格检查关口 | 缺少自动处理中间任务 | 面网格成功后执行计划的非网格任务并准备体网格参数 | 已实现基础流程；几何分支待实机验证 |
| 条件任务链 | 固定步骤列表，几何分支不完整 | 由 `workflow_plan.py` 与共享 JSON 规则按几何类型、开关构造步骤 | 部分实现；任务契约尚待 Fluent 实机核对 |
| 封盖、创建区域、共享拓扑 | 模板步骤未包含 | 条件出现，并在缺少必要封盖设置时暂停 | 部分实现；子任务参数和共享拓扑待实机验证 |
| 多区域任务 | 静态 schema 尚未收录动态任务 | 采集真实任务及参数后接入 | 未实现；当前选择多区域会明确暂停并提示缺少定义 |
| 参数条件显示 | 部分 Fluent 函数及嵌套条件未被处理 | 结合任务及参数值过滤字段，继承父条件并隐藏内部字段 | 部分实现；完整 Fluent 前端一致性待验证 |
| 目标队列与旧模板 | 阶段状态未随模型初始化 | 每个目标重置阶段和旧 `at_use` 状态；新模型导入后准备面网格 | 已实现基础行为；API 集成验证待完成 |

导入后“未开始”的原有原因链：`_import_current_model` 只将当前步骤索引设为 `add_local_sizing`；写入与回读在 `enter_step`；`native_task_changed` 在 Fluent 当前任务切换后才调用 `enter_step`。本次改动将局部尺寸准备直接接到导入成功之后，Fluent 当前任务事件只记录状态。阶段进入 `surface_ready` 才表示面网格参数已写入并回读成功。

## 描述几何决定后续任务

| Geometry Type 与其他选项 | Fluent 中间任务及专属设置 | 平台要求 |
| --- | --- | --- |
| 只有实体区域 | 按封盖需求出现封闭流体区域：名称、边界类型、封盖类型、标签/区域；创建区域：预计流体区域数、死区命名 | 依选择生成任务，不把两组设置混入描述几何 |
| 只有流体区域且无空腔 | 更新边界：按标签/区域的边界名称与边界类型表 | 保留现有表格编辑，并显示实际任务 |
| 流体与实体区域和/或空腔 | 按需要封盖、更新边界、创建区域、更新区域 | 保留更新边界，并按具体选择生成其余任务 |
| 应用共享拓扑＝Yes | 应用共享拓扑：方法、间隙、界面标签及对应高级项 | 新增条件任务；与非共形选项互斥 |
| 启用多区域网格＝Yes | 添加多区域控制、生成多区域网格，字段由 Fluent 25.2 实机采集 | 采集并接入；缺少定义时明确提示，不静默执行 |

Fluent 的任务树会受几何和已执行任务影响。静态计划必须与实时任务树核对；不一致时指出缺失或额外的任务并暂停。区域类型与 Fluent region 的映射继续暂缓。

## 参数条件差异

| 阶段 | Fluent 前端条件 | 当前平台问题与实现办法 |
| --- | --- | --- |
| 导入几何 | CAD 显示“单位”；Mesh 才显示“文件单位” | 用 `file_format` 判定；模板不保存目标文件名 |
| 面网格 | 导入表面网格时才可选择重划边界；曲率/邻近决定相关尺寸字段；自定义尺寸文件决定文件框 | 为 Fluent 函数及嵌套条件建立明确规则；内部附属对象不展平成当前任务的用户输入 |
| 边界层 | 偏移方法决定首层高度/纵横比、过渡比和增长率；选“指定标签/区域”才显示相应列表 | 解析 `FaceScope` 条件，按每个子任务的选择显示，不联动标签组 |
| 体网格 | tetra/poly 与 hexcore/poly-hexcore 参数不同；全局边界层/薄体选项取决于前序任务 | 处理嵌套条件及前序任务状态；过滤继承的其他任务参数和内部列表 |

## 实施记录与验收

1. 导入后依次写入并核对局部尺寸、执行使其生效的任务、写入并核对面网格参数。全部通过才显示“面网格设置已就绪”。
2. “生成面网格”只执行 `create_surface_mesh`。成功后自动执行适用的几何描述、边界/区域、边界层等非网格任务，写入并核对体网格参数；全部通过才显示“体网格设置已就绪”。
3. “生成体网格”只执行 `create_volume_mesh`。缺失标签、未补齐的旧 `at_use` 值、回读不一致及任务异常均标明任务和字段并停在当前阶段，修正后可重试。
4. 后端阶段测试覆盖导入后立即应用局部尺寸、纯流体/实体/混合任务分支、缺失 `at_use` 修复重试、准备期间不生成网格、两个关口分别生成对应网格；结果 **5 项通过**。前端条件显示测试 **5 项通过**，实时页面阶段测试 **3 项通过**，TypeScript 类型检查通过，Python 源码编译检查通过。
5. API 集成用例 `test_live_meshing_session_advances_steps_and_models` 在当前环境运行时持续等待，未在本轮获得完成结果；它不计为通过。环境 Python 未安装 PyFluent，测试通过注入 `camel_to_snake_case` 模块桩运行，因而不能证明 PyFluent 接口与真实安装一致。
6. Fluent 25.2 实机验证：**待验证**。还需在实际 Fluent 中核对三种几何类型、封盖/共享拓扑参数、多区域任务、面网格及体网格两个生成关口。自动测试不能替代这项验证。

## 本轮代码落点

- `backend/app/meshing/workflow_schema.json` 保存静态步骤顺序与条件规则；`backend/app/meshing/workflow_plan.py` 根据模板中的几何类型和开关生成步骤计划。
- `backend/app/services/meshing_live.py` 管理阶段状态、导入后自动准备、两个专用网格任务、失败重试以及队列换模型时重置并重新准备。Fluent 当前任务回调只观察状态。
- `src/renderer/src/pages/MeshingLiveSyncPage.tsx` 显示准备、就绪、生成和失败状态；只有对应阶段就绪时显示生成按钮，并提供准备重试入口。
- `src/renderer/src/pages/meshingPreset.ts` 和模板编辑页根据条件过滤参数；`src/shared/contracts.ts` 传递阶段状态。
- 动态多区域任务未纳入静态 schema。用户选中该分支时后端返回可理解的缺少定义提示并暂停；采集 Fluent 25.2 实际任务与参数后再扩展契约。

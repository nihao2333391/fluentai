# Fluent AI｜02-B 文丘里边界层工程辅助工作流

**版本：V0.1**

**所属模块：02 工程辅助 Agent 与能力库**

**状态：业务流程草案；工程算法复用已有封装，具体字段待代码审查**

## 1. 业务目标与范围

文丘里边界层工程辅助 Agent 用于支持用户完成 Add Boundary Layers 工作流中的方法选择和关键参数推荐。

V1 专注两个选择：

- Uniform：重点计算 First Height，并提供配套层数等参数。
- Smooth Transition：重点推荐 Number of Layers，并提供配套增长率、过渡比例等参考设置。

Agent 的推荐属于工程初始设置建议，最终合理性需要通过实际生成的网格及求解结果验证。

工程辅助 Agent 不直接修改 Fluent 模板表单。

## 2. Agent 主动引导

### 2.1 首次进入

当模板所属目录具有文丘里边界层专业能力时，系统显示预设欢迎内容。

例如：

“我可以协助你设置文丘里管的边界层，包括 Uniform 与 Smooth Transition 两种方法。你可以先了解方法区别，也可以提供模型结构和工况，让我进行分析推荐。”

提供快捷问题：

- 了解两种方法。
- 根据我的模型推荐。
- 暂时不需要。

首次欢迎状态在数据库中记录，重新打开模板时恢复历史会话。

### 2.2 了解方法

用户选择介绍方法时，Agent 说明：

**Uniform**

强调第一层网格高度的明确控制，适合需要根据目标壁面 y+ 估算 First Height 的情况。

**Smooth Transition**

强调边界层与外部体网格的尺寸过渡，首层厚度受到局部网格尺寸等因素影响。

介绍中提供方法的特点、局限、适用场景和必要的验证方式。

用户阅读后可选择继续分析自己的模型。

## 3. 工程信息收集

### 3.1 输入信息分类

工程信息分为四类：

| 分类 | 主要信息 |
|---|---|
| 几何结构 | 入口直径、喉部直径、侧支位置与口径、关注区域 |
| 物理工况 | 流体物性、速度或流量、边界条件 |
| 研究目标 | 关注压力、速度、温度混合或壁面流动的哪个方面 |
| 网格设计目标 | 湍流模型、目标 y+、增长率、局部网格尺寸及资源约束 |

这些信息不要求用户一次性全部填写。

Agent 应根据当前问题和计算分支，动态判断哪些参数是必需的。

### 3.2 图片输入

用户可以上传：

- 模型结构尺寸图。
- Fluent 边界条件截图。
- 现有网格设置截图。

图像识别结果应整理为结构化信息，并展示关键尺寸、单位及数据来源供用户确认。

图像中无法确认的参数应向用户询问。

只有在当前模型支持图片输入时才执行多模态分析。

### 3.3 缺失参数机制

Agent 每次分析前检查已有数据。

例如：

用户提供了入口速度与水的物性，但尚未提供喉部口径。

如果当前选择的 Uniform 计算需要喉部特征尺寸，则 Agent 主动询问：

“请提供需要设置边界层区域的喉部直径，或者上传能看清该尺寸的结构图。”

缺失参数检查应由工具输入 Schema 与工程规则共同决定，而不能仅依赖模型随意猜测。

### 3.4 参数来源记录

每个关键输入需要记录：

- 参数 ID。
- 数值与单位。
- 数据来源。
- 所属几何区域。
- 是否经过用户确认。
- 使用的工程假设。

数据来源可以是：

用户输入、图片识别、已有配置、工程估算或计算工具推导。

## 4. 方法推荐

### 4.1 判断依据

Agent 应综合考虑：

1. 模型的几何变化特征。
2. 重点研究区域。
3. 是否需要明确控制首层高度。
4. 局部表面网格尺寸及变化。
5. 当前工况及目标壁面分辨率。
6. 两种方法对网格生成及后续验证的潜在影响。

V1 的方法推荐以专业知识和可核查的工程分析为主，不额外开发复杂的最优方法判定算法。

### 4.2 推荐结果

结果包括：

- 已识别模型特点。
- 已使用的工况信息。
- 研究目标。
- Uniform 的特点及适用性。
- Smooth Transition 的特点及适用性。
- 当前优先推荐的方法。
- 推荐依据及待验证条件。

推荐方法应与当前输入保持对应。模型几何、物理参数或研究目标变化后，允许重新分析。

### 4.3 用户选择

Agent 提供两个可点击选项：

**采用 Smooth Transition**

**采用 Uniform**

用户可以选择任意分支，即使它不是当前推荐的方法。

系统记录实际选择结果，进入对应计算流程。

## 5. Uniform 分支

### 5.1 目标

根据目标壁面 y+、流体性质和局部流动条件，估算边界层第一层网格高度。

### 5.2 工具输入 Schema

| 参数 ID | 含义 | 单位 |
|---|---|---|
| fluid_density | 流体密度 ρ | kg/m³ |
| dynamic_viscosity | 动力黏度 μ | Pa·s |
| characteristic_velocity | 研究区域特征速度 U | m/s |
| hydraulic_diameter | 特征水力直径 D | m |
| target_first_yplus | 第一层网格中心目标 y+ | 无量纲 |
| target_region | 目标壁面区域 | 区域标识 |

对于当前研究案例，目标第一层 y+ 可默认取 1，但需要允许调整。

所有必需参数必须经过校验，才能执行计算。

### 5.3 已有计算方法

优先复用既有 Uniform First Height 封装。

当前既有计算路线为：

\[
Re=\frac{\rho UD}{\mu}
\]

\[
C_f=0.079Re^{-0.25}
\]

\[
u_\tau=U\sqrt{\frac{C_f}{2}}
\]

\[
y=\frac{y_1^+\mu}{\rho u_\tau}
\]

\[
h_1\approx2y
\]

其中：

- Re：雷诺数。
- Cf：上述经验关系下的摩擦系数，采用 Fanning 定义。
- uτ：估算摩擦速度。
- y：第一层网格中心到壁面的估算距离。
- h₁：估算的完整第一层网格厚度。

该模型属于简化工程估算。公式适用范围、管内流动假设及局部速度选取必须在接入时复核。

### 5.4 几何变化处理

不同文丘里模型必须使用各自的有效口径与工况。

若采用连续性方程估算喉部速度，应说明适用假设。

对于存在侧向注入、混合和复杂局部流动的区域，不应直接把简单圆管速度关系当作精确结果。

### 5.5 计算输出

至少提供：

- 目标设置区域。
- 采用的输入和单位。
- Re、Cf、uτ。
- First Height 的计算结果。
- 推荐填写的参数表。
- 计算假设、风险及待验证项目。

## 6. Smooth Transition 分支

### 6.1 目标

结合目标壁面分辨率和经验覆盖范围，推荐边界层层数。

该分支优先复用已有《文丘里管_边界层层数推荐算法说明》。

### 6.2 工具输入 Schema

| 参数 ID | 含义 |
|---|---|
| first_yplus | 第一层中心目标 y+ |
| target_outer_yplus | 经验覆盖终点 y+ |
| growth_rate | 层厚增长率 |
| target_region | 关注的壁面区域 |

当前研究案例的参考值：

- 第一层目标 y+ = 1。
- 经验覆盖终点 y+ = 50。
- 增长率 r = 1.2。

其中 y+ = 50 是当前项目为覆盖近壁不同区域而采用的工程设计目标，并不是所有 CFD 模型都必须满足的固定标准。

### 6.3 层数算法

现有封装采用：

\[
N=\left\lceil
\frac{
\ln\left(1+\frac{(r-1)y_{\mathrm{target}}^+}{2y_1^+}\right)
}{
\ln r
}
\right\rceil
\]

当上述三个参数分别取 1、50、1.2 时，得到理论层数 N = 10。

这里的 N 表示基于所采用简化层厚增长假设的理论推荐，不代表 Fluent 一定在所有壁面位置完整生成 10 层。

### 6.4 输出要求

至少包含：

- 推荐层数。
- 采用的 y+ 设计范围。
- 增长率。
- 理论覆盖结果。
- Smooth Transition 相关参考设置。
- 首层高度由实际网格尺寸等因素决定的说明。
- 实际生成网格后的待验证事项。

不得把 Uniform 分支计算得到的 First Height 直接当作 Smooth Transition 自动生成的首层厚度。

## 7. Fluent 参数映射

两个分支的结果最终应统一映射到 Add Boundary Layers 参数 Schema。

| Fluent 参数 | Uniform | Smooth Transition |
|---|---|---|
| Offset Method Type | uniform | smooth-transition |
| Number of Layers | 层数候选 | 算法推荐层数 |
| Growth Rate | 项目参考值 | 项目参考值 |
| First Height | 计算得到 | 不作为该方法的直接输入推荐 |
| Transition Ratio | 依据实际面板确定 | 项目参考值，待核验 |
| Add in | 由实际流体区域决定 | 由实际流体区域决定 |
| Grow on | 根据目标壁面确定 | 根据目标壁面确定 |

第一版的专业算法主要负责方法选择以及 Uniform First Height、Smooth Transition Number of Layers。

其他字段可以提供经过核实的案例参考值，但必须标记其来源和适用条件。

真实 Fluent 字段、单位和设置方式以现有项目使用的 Fluent 2025 R2 工作流为准。

## 8. 统一推荐结果 Schema

建议输出对象至少包含：

- recommendation_id
- template_id
- selected_method
- source_inputs
- calculated_values
- fluent_parameters
- assumptions
- warnings
- verification_items
- tool_id
- tool_version
- created_at

工具结果由后端计算并校验。

Agent 负责根据这些结构化结果生成面向用户的解释。

同一推荐结果在对话重新打开后能够原样恢复。

## 9. 前端结果卡片

每份推荐卡片至少展示：

**方法名称**

例如 Uniform。

**推荐参数**

例如 Number of Layers、Growth Rate、First Height。

**计算依据**

显示输入、公式及中间结果。

**工程假设**

例如采用的局部流速、目标壁面区域和经验摩擦系数关系。

**验证要求**

如实际生成层数、网格质量及求解后的 Wall Yplus 分布。

V1 支持用户阅读和复制参数，随后手动填写模板。

## 10. 两种方法的分支切换

用户在获得 Smooth Transition 推荐后，可以返回选择 Uniform。

系统应：

1. 保留已有模型和工况信息。
2. 判断 Uniform 所需参数是否完整。
3. 补充询问缺失内容。
4. 调用 Uniform 工具。
5. 保留两次独立的计算记录。

不同分支的参数结果不得互相覆盖。

同一模板会话中，可以保存多个推荐结果供用户比较。

## 11. 工具和 Agent 的责任边界

模型负责：

- 理解用户请求。
- 识别已有信息。
- 询问缺失参数。
- 基于知识分析方法适用性。
- 解释计算结果。

后端计算工具负责：

- 参数校验。
- 单位转换。
- 执行确定性计算。
- 返回结构化结果。
- 记录工具版本与异常。

模板编辑器负责：

- 提供实际 Fluent 参数表。
- 由用户手动填写推荐值。
- 按既有流程保存和执行。

## 12. 异常与重新计算

至少覆盖：

- 缺少口径。
- 未明确计算区域。
- 缺少流体物性。
- 速度与流量单位不一致。
- 用户修改目标 y+。
- 工具运行失败。
- 计算超出经验公式适用范围。
- 切换方法后出现参数不适用。
- 模型返回无法映射到 Fluent 的字段。
- 对话中断后恢复历史推荐。

当影响计算结果的输入发生变化时，应将旧结果标记为基于旧输入计算，并允许重新计算。

## 13. V1 验收标准

1. Agent 能主动介绍边界层方法。
2. 能够接受模型结构和工况信息。
3. 能发现缺失的关键工程参数并向用户提问。
4. 能推荐方法并说明依据。
5. 用户可以自由选择 Uniform 或 Smooth Transition。
6. 两种方法分别调用已有计算工具。
7. Uniform First Height 随模型尺寸和工况变化。
8. Smooth Transition 层数根据既有规则计算。
9. 所有计算结果有明确的输入、单位和来源。
10. 参数能对应真实 Fluent 表单。
11. 用户能够切换分支并保留历史结果。
12. 模型不能伪造工具计算结果。
13. 用户能够根据推荐手动完成参数设置。

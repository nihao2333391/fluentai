## Current Boundary

- Name validation uses the catalog exposed after geometry import. Names that only appear after surface-mesh generation cannot be validated while honoring the no-mesh rule.
- Direct `.dsco` import can block in standalone Fluent Meshing. The verified native route is the generated `.pmdb`; `.scdoc`, STEP, IGES, PMDB, and listed exchange formats are supported.
- Fault-tolerant `Identify Construction Surfaces` and `Create Local Refinement Regions` still have no complete compound-child template because PyFluent raises `RecursionError`. They remain explicitly unavailable rather than guessed.
- The apply engine writes workflow settings but does not save a modified `.wft` or generate a mesh.

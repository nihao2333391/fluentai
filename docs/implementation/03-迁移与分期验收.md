# Fluent AI｜数据迁移与分期验收

**版本：V1 技术设计基线 0.1**  
**状态：业务规则已确认；迁移脚本编写前须基于数据库现状完成只读盘点**

## 1. 现状与兼容基线

当前服务使用 SQLite 迁移表管理升级。`automations` 保存 Solver 预设；`meshing_automations` 保存网格预设；`models` 保存原始文件路径、大小及修改时间；`jobs` 和 `sync_logs` 保存已有执行信息；`meshing_result_archives` 保存已归档网格与记录路径。

网格实时会话当前由服务内存管理，无法作为重启后恢复的权威来源。新增任务设计须将任务、状态事件、会话关联和产物索引写入 SQLite；进程重启后，曾处于活动状态的会话标记为 `interrupted`，只恢复展示数据。重新继续 Fluent 前须核对真实连接及模型状态。

## 2. 已确认的数据迁移规则

1. 将已有网格预设放入“未分类”零件目录，沿用原 automation ID、名称、描述、参数 JSON 与创建/更新时间。
2. 首次迁移创建目录时用稳定迁移标识避免重试重复建目录；目录记录与能力空间初始化需可分别诊断。
3. 不把 Solver `automations` 隐式转换为网格模板；两者工作流类型不同，保持既有记录和行为。
4. 不批量复制或移动用户的模型文件。旧模型记录保留路径；迁移后任务引用模型 ID，并保存文件名、路径、大小、修改时间快照。
5. 被任务引用的模型从后续模板应用选择器中隐藏，但保留原始记录与历史任务引用。原文件被外部移动或修改时，明确标记引用异常，不以历史快照冒充文件仍然存在。
6. 已归档结果保持原归档路径与记录 ID；迁移时为可验证的归档补建任务产物索引。迁移无法定位文件时保留原记录并登记异常，不删除原记录。
7. 任务软删除保留任务及产物归属索引。默认保留文件；勾选清理时，仅清理确认属于目标任务且没有其他引用的文件。
8. 删除运行任务先请求停止；收到执行服务确认停止后才可删除。Fluent 原子调用无法被保证强制取消，停止未确认时拒绝删除并说明原因。

所有迁移使用新增数据库版本。升级须可重复安全执行；成功后核对记录数、外键关系、JSON 可解析性及文件引用；错误须回滚迁移事务，或为非事务文件操作记录可重试补偿步骤。发布前在数据库备份副本验证，不覆盖现有用户数据库做试跑。

## 3. 分期实施与用户验证

### 阶段一：数据契约及参数映射

建立实体、接口、状态与参数映射基线；检查旧表、归档文件、运行会话和真实 Fluent 字段。验收：单一责任源清楚；参数方法条件、单位与验证级别可追溯；迁移前后记录映射有审计证据。

### 阶段二：目录与模板

加入一级目录、目录能力空间、模板草稿保存及发布版本；复用现有 Fluent 预设结构。验收：重启后草稿恢复；并发保存冲突有提示；发布后新草稿不改写旧版本；用户可在未分类目录找到原网格预设。

### 阶段三：持久任务与 Fluent 排队

应用模板时创建 task，保存模板版本、模型引用及配置快照；将运行会话和事件与任务关联；队列串行控制共享 Fluent。运行状态后台推进，页面轮询/刷新只读取持久状态；卡片采用面网格和体网格两个主节点，细节见任务阶段与事件。验收：多个任务隔离；首任务等待用户操作时队列遵守当前占用规则；进入任务返回原工作流；重启后活动任务显示中断；任务产物与原模型分开归属。

### 阶段四：Agent 与专业能力

先评估 Agno 与当前 FastAPI、依赖版本、SQLite/会话存储、流式响应及取消行为的兼容性，再决定最小集成方式。接入全局模型配置、模板隔离会话、知识检索、已授权工具和工程参数快照。验收：切换全局模型不串会话；工具仅执行注册且授权的实现；输入变化保留并标记旧推荐；Agent 推荐不直接改模板。

### 阶段五：集成验收

完善任务产物查看与删除、推荐结果卡片、拓展台占位页、数据迁移和完整端到端验证。成功标准：目录 → 模板 → Agent 辅助 → 发布 → 选择模型 → 独立任务 → 操作提醒 → Fluent 网格生成 → 结果保留，可在关闭并重启软件后查看历史任务和结果索引。

## 4. 测试矩阵

- 数据库：从旧版本升级、重复迁移、迁移失败回滚、外键和记录数量核对、备份恢复。
- 模板：自动保存、发布快照、版本冲突、历史任务引用旧版本。
- 任务：重复应用、队列顺序、用户操作等待、取消/异常、sidecar 重启、提醒保留与清除时机。
- 资源：默认删除保留文件、显式清理仅命中独占产物、模型被引用后隐藏、外部文件缺失提示。
- 参数：Uniform/Smooth Transition 条件、单位转换、缺参校验、工具版本追溯、旧推荐过期；另做 Fluent 2025 R2 实机读写与回读验证。
- Agent：模板会话隔离、全局模型切换、工具授权、模型/API 错误、结构化参数恢复。

模拟 Fluent 测试验证业务状态和代码路径；真实 Fluent 测试验证实际接口、单位及工作流效果；桌面端手动验收验证用户能够找到待操作任务、返回对应 Fluent 页面并完成操作。这三类证据分别记录。

## 5. V1 明确保留的范围

V1 采用单 Fluent 执行队列；不实现多个 Fluent 实例并行、完整断点恢复、失败自动重试、Agent 自动填写模板、生成或注册工具、复杂能力编辑界面。拓展台仅提供占位页。遗留模板的高级版本编辑及目录级级联删除不新增自动行为。

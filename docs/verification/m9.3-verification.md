## Implemented

### Recent-session restore

- Successful model open persists the most recent model.
- Successful Solver apply persists model and automation IDs.
- Successful Meshing apply persists model and Meshing automation IDs.
- Authenticated endpoint:
  - `GET /api/session/recent`
- My Automations displays the last model/automation and can reopen the apply dialog with both preselected.

### Job progress and cancellation

- Task status surface now opens a detailed progress list.
- Each job shows status, type, latest message, timestamp, progress bar, and terminal state.
- Running and queued jobs expose a cancel action.
- Authenticated endpoint:
  - `POST /api/jobs/{id}/cancel`
- Cancelled jobs are terminal and cannot be overwritten by a late worker completion.
- Solver and Meshing workflows check cancellation between connection, model/geometry load, and apply stages.
- Cancellation is cooperative; an in-progress atomic Fluent call cannot be interrupted from Python.

### Sync-log filtering

- Server-side filters:
  - direction;
  - status;
  - Solver automation ID;
  - Meshing automation ID;
  - model ID;
  - text search over target, message, and payload.
- My Automations exposes direction, status, and search controls.

## Implemented

- `electron-builder` 26.15.3 integrated.
- Windows x64 NSIS installer target.
- Local Electron distribution used to avoid runtime downloads.
- Reproducible packaging scripts:
  - `pnpm package:dir`
  - `pnpm package:win`
- Bundled sidecar strategy:
  - standalone Python 3.12 runtime;
  - runtime site-packages;
  - backend source;
  - generated Meshing schemas.
- Electron sidecar launcher now resolves `resources/sidecar/python/python.exe` when packaged.
- Packaged sidecar sets `PYTHONHOME`, `PYTHONPATH`, and `PYTHONNOUSERSITE`.
- Sidecar startup timeout increased from 20 seconds to 60 seconds after cold-start validation exposed PyFluent preload latency.
- Installer smoke mode loads the real renderer, waits for the packaged sidecar to become ready, writes a machine-readable report, and exits automatically.
- Silent installation and silent uninstall validation.

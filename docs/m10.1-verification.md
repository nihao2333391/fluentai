## Implemented

### Application branding

- Generated a 512x512 Fluent AI application icon.
- Configured the Windows executable and NSIS installer to use `build-resources/icon.png`.
- Icon generation is reproducible through `scripts/generate-app-icon.ps1`.

### Database backup and restore

- SQLite backup uses the native backup API.
- Every backup passes `PRAGMA integrity_check`.
- A daily backup is created automatically during sidecar startup when the newest backup is older than 24 hours.
- Manual backups are available from Settings.
- The latest 10 backups are retained.
- Restore creates a `pre-restore` safety backup first.
- Path traversal is rejected by resolving and validating the backup path.
- Authenticated endpoints:
  - `GET /api/system/backups`
  - `POST /api/system/backups`
  - `POST /api/system/restore`
- Settings UI lists recent backups and exposes backup/restore actions.

### Sidecar slimming

Removed runtime content that the application does not require:

- Python test suite and idle/turtle/venv modules;
- Tcl, headers, import libraries and base scripts;
- pip, pytest, mypy, ruff, type stubs and related development packages.

Sidecar size decreased from approximately 300.1 MB to 263.1 MB. The pruned sidecar still passes independent startup, authentication, database readiness, and shutdown verification.

The final Windows installer is approximately 169.5 MB and passed silent installation, packaged renderer loading, bundled-sidecar readiness, and uninstallation.

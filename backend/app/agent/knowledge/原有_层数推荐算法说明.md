# 文丘里管近壁面网格层数推荐算法 · v1.0

> 适用场景：Fluent Meshing / k–ω SST / 文丘里管内部冷热水混合。  
> 目标：让没有读过此前讨论的工程师理解近壁面区域、为什么选 `y⁺=50`、层数从哪里计算，以及最终修改哪些 Fluent 参数。  
> **状态：设计阶段的初始推荐规则（尚非物理精度最优证明）。**

## 0. 一分钟读懂

管道内流体在固体内壁附近存在速度梯度。我们从**内壁沿法向向管内流体方向**放置多层棱柱单元（Inflation / Prism Layers），来提高近壁面流动的数值分辨率。

`y⁺` 是**无量纲壁面距离**，不是管道的长度，不是外壁厚度，也不是 Fluent 中要输入的温度或速度。

| 典型近壁区域 | 常用的 y⁺ 范围 | 简明含义 |
|---|---|---|
| **黏性底层** (Viscous Sublayer) | 约 0–5 | 分子黏性主导，靠壁面速度梯度强 |
| **缓冲层** (Buffer Layer) | 约 5–30 | 黏性效应和湍流效应共同影响 |
| **对数层** (Log Layer) | 通常约从 30 开始 | 进入可近似使用对数速度规律的部分区域；其外边界随流动变化 |

**本项目的设计目标：** 第一层单元中心 `y₁⁺ = 1`；让多层网格的**最外侧位置**延伸到 `y_target⁺ = 50`，即覆盖黏性底层与缓冲层，并进入对数层的初始部分。**这里的 50 是项目自行定义的经验覆盖目标，并非 k–ω SST 或 Ansys 规定的阈值；它不表示覆盖完整对数层。**

在层间增长率 `r = 1.2` 的理想几何增长假设下，计算得到推荐层数 **N = 10**。

## 1. 物理概念与单位

壁面距离无量纲化：

`y⁺ = ρ·u_τ·y / μ`

- `ρ`：流体密度，kg/m³。
- `μ`：动力黏度，Pa·s。
- `u_τ = √(|τ_w| / ρ)`：摩擦速度，m/s；`τ_w` 为壁面剪切应力。
- `y`：从**管道内壁**向内、到相应流体位置的法向距离，m。

`y₁⁺ = 1` 指第一层**网格单元中心**的目标 y⁺，不是第一层完整厚度等于 1；设计公式把第一层中心距离近似为首层完整厚度 `h₁/2`。

`y_target⁺ = 50` 指多层棱柱网格总厚度 `H` 的**外缘位置**的目标无量纲距离（网格从内壁向流体内部延伸），不是文丘里管的外壁、出口或自由流边界。

## 2. 为什么选择 50？如何更改？

这是一个**透明、可编辑的工程经验目标**：

1. 近壁面常用分区为 `0–5`、`5–30` 和从 `30` 左右起始的对数层。
2. 希望棱柱网格至少穿过前两个区域，且稍微进入第三个区域，于是选择 **50** 作为**初版**的外侧覆盖目标。
3. 其物理含义是“**计划覆盖到对数层起始部分**”，不代表“已经证明这根文丘里管的物理边界层厚度就是 y⁺=50”。
4. 若工程师认为应覆盖更远，可修改成 100；若只要求达到缓冲层末端，可设为 30。更改后的层数由同一公式重新计算。

**重要的证据边界**：50 的选择不是由文丘里管尺寸自动推导的；此前已知 10 层表现较好，不能再把选择 50 得到 10 层说成独立证明“10 层全局最优”。它是一条可复现的设计规则，需要用实际网格和求解结果验证。

## 3. 核心层数公式（算法）

用户输入：

- `y1_plus`：第一层单元中心目标，默认 1。
- `outer_y_plus`：整组棱柱层外侧目标，默认 50。
- `growth_rate`：层厚增长率，默认 1.2。

理想几何增长模型：`h_i = h₁ · r^(i−1)`；假设第一层中心在层厚中点，则 `h₁⁺ = 2·y₁⁺`。

于是棱柱层总厚度的壁面单位表达式为：

`H_N⁺ = 2 · y₁⁺ · (r^N−1) / (r−1)`（r>1）

要求 `H_N⁺ ≥ y_target⁺`，反解：

`N = ceil[ ln(1 + (r−1)·y_target⁺/(2·y₁⁺)) / ln(r) ]`（r>1）

若 `r = 1`，则 `N = ceil(y_target⁺/(2·y₁⁺))`。输出为达到该经验目标的**最小理论整数层数**。

例：`y₁⁺ = 1`，`y_target⁺ = 50`，`r = 1.2`：

- 未取整的计算结果：`N = 9.827469`
- 向上取整后：**`N = 10`**
- 理论总覆盖：**`H₁₀⁺ ≈ 51.9174`**（达到目标 50）

提示：当三个无量纲设计输入保持不变时，A（紧凑）、B（中等）、C（长流）三种不同尺度文丘里管也会**得到相同的理论层数 10**。这不是几何对实际网格无影响；不同几何和工况仍会改变实际首层厚度、流动状态、网格质量和真实 Wall Yplus。

## 4. Fluent Meshing 最终应修改哪些参数？

### 4.1 推荐作为当前实验基准：Smooth Transition

与此前实际截图对照：

| Fluent → Add Boundary Layers 字段 | 截图默认 | 初始候选设置 | 是否修改 |
|---|---:|---:|---|
| `Add Boundary Layers?` | yes | yes | 保持 |
| `Offset Method Type` | smooth-transition | **smooth-transition** | 保持 / 人工选择 |
| `Number of Layers` | 3 | **10** | **修改** |
| `Growth Rate` | 1.2 | **1.2** | 保持 |
| `Transition Ratio` | 0.272 | **0.272** | 保持默认、待网格验证 |
| `Add in` | fluid-regions | fluid-regions | 保持 |
| `Grow on` | only-walls | only-walls | 保持（如只研究局部壁面，可另设选择范围） |

**注意**：Smooth Transition 不是通过 `y₁⁺=1` 直接锁定首层高度。它使用局部网格几何和 Transition Ratio 自动确定实际高度；此处算法 **只输出一个物理目标驱动的候选层数 10**，不能保证生成后真的满足 `y₁⁺=1` 或 `H⁺≈51.92`。

### 4.2 若工程师改选 Uniform

- `Offset Method Type = uniform`。
- `Number of Layers = 10`（同一理想覆盖规则给出的候选层数）。
- `Growth Rate = 1.2`。
- **需要额外输入 / 估算 First Height [mm]**：`h₁ = 2·y₁⁺·μ/(ρ·u_τ)`（单位换算为 mm）。其中 `u_τ` 需要由壁面剪切估计或先期 CFD 求解获得；不应直接使用 Smooth Transition 的自动首层高度，也不应把默认 0.7 mm 视作已经满足 SST。

## 5. 工程使用与验证流程

`读取算法配置 → 计算候选 N → 把 N 和方法参数写入 Fluent → 生成体网格 → 记录实际网格结果 → SST 求解 → 查看 Wall Yplus → 验收或调整`。

初版最少记录：

- **网格阶段**：实际局部层数、最小正交质量、最大偏斜度、总单元数。
- **求解阶段**：喉部、侧管交汇处 `Wall Yplus` 云图与统计（尤其第一层附近的 y⁺ 分布），以及收敛情况。
- **物理结果**：喉部压力、侧管质量流量、出口温度或混合指标；若要证明精度提升，应增加网格无关性对照。

在之前的某一组实验中，你测得 Smooth Transition：`3 层 → 最小正交质量 0.236`、`10 层 → 0.304`、`20 层 → 0.0664`。这些数据说明 10 层是**该组已测方案中按最小正交质量评价较好的候选值**，不等同于已经证明其 Wall Yplus 及物理结果最优。

## 6. 软件封装说明

交付文件：

- `boundary_layer_layers.py`：纯 Python 算法，无第三方依赖；支持 `r=1` 和 `r>1`。
- `boundary_layer_config.json`：工程师可编辑参数配置。

运行命令：

```bash
python boundary_layer_layers.py boundary_layer_config.json
```

输出 JSON 中：

- `nominal_calculation.recommended_layers`：理论层数（本例为 10）。
- `nominal_calculation.nominal_outer_y_plus`：理想覆盖终点（本例约 51.92）。
- `fluent_candidate_settings`：可映射到 Fluent Meshing 表单的参数。
- `status = INITIAL_DESIGN_NOT_VALIDATED`：还需验证实际网格与求解结果。

**工程师最常修改的参数**：`design_targets.first_cell_y_plus`、`design_targets.outer_y_plus`、`design_targets.growth_rate`；必要时再修改 `fluent_controls.offset_method_type`、`fluent_controls.transition_ratio` 和生长区域。
